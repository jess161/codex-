# 刃之进化 / BLADE EVOLUTION

中文 2D 俯视割草游戏。当前源码已从 `6080d8d` 的“十二把刀＋三把弓”重构为四种普通武器：**刀、剑、弓、矛**。开局、首页、图鉴和旋转鉴赏均只提供这四种选择。本轮不做技能树，也不沿用旧名刀的专属被动与主动绝招。

本轮源码改动与已发布网页是两件事：[上次发布的试玩](https://jess161.github.io/codex-/) 不能用来判断本轮代码是否已上线。准确范围与验收见 [四种基础武器重构](docs/gdd/blade-evolution-basic-weapons-v1.2.md)。

## 四种手感

| 武器 | 基础攻击 | 初始间隔 | 初始距离 | 特点 |
| --- | --- | --- | --- | --- |
| 刀 | 横扫 | 0.70 秒 | 90 | 170° 宽扇形，同时命中前方多个敌人 |
| 剑 | 快斩 | 0.34 秒 | 80 | 76° 窄幅快斩，出手与收势更短 |
| 弓 | 自动射击 | 0.58 秒 | 340 | 自动瞄准可见目标，一次一箭，命中首个敌人后消失 |
| 矛 | 直线贯穿 | 约 0.81 秒 | 150 | 沿前方窄直线贯穿所有敌人，刺出前跟随原目标瞄准 |

刀剑的伤害判定与斩击方向同步，矛在接触帧伸至完整距离。矛的判定沿线保持固定宽度，不使用扇形，也不命中身后。武器的钢刃木柄造型在卡片、战斗与鉴赏中共用。

## 保留的玩法

- 每局从 Lv.1 成长至最高 Lv.30，6 分钟生存后进入最多 45 秒的首领战。掌握阶段在 Lv.1 / 6 / 12 / 20 / 28 自动提升，不分配技能点或打开技能树。基础攻击方式随成长保持不变。
- 六组三十件道具、六种品质，打怪掉落在原地，走近直接拾取；携带数量不限，重复拾取升级，满级退出掉落池。同组道具自动获得组合效果。
- 怪物、精英、首领、回血食物、高等级压力、六种战场主题、声音与轻量画面继续使用现有系统。
- 经验球逐颗保留，不合并、不远程入账。菜单、暂停和切后台会清除移动输入；松开摇杆立即停止。
- 保留击中反馈、战斗力、成就、自动保存和旋转鉴赏。基础武器不显示“绝招”按钮，Q 不触发旧技能；道具自身的效果仍正常生效。

## 存档兼容

沿用 `blade-evolution-save-v1` 键与 v8 结构，读取 v1—v8 历史存档。旧弓映射到普通弓，旧匕首和剑类映射到普通剑，其余旧刀映射到普通刀。保留等级、经验、生命、旧锻造、已获道具、地面掉落、世界进度、随机流和永久战绩；旧武器的蓄势、专属状态、未完成攻击与在飞技能清除，避免带入新武器。

旧对局的原时长与经验节奏继续保留，旧选择菜单仍按既有规则转为地面奖励。新基础武器的进行中攻击、箭矢与道具可完整保存并继续。旧编号 0—14 仅在内部保留以验证和转换历史数据，新编号为 15—18；实际可选列表以 `BLADE_CATALOGUE` 为准。

## 开发与验证

需要 Node.js 20.19+ 或 22.12+：

```bash
npm ci
npm run dev -- --port 4173
npm test
npm run test:basic-weapons
npm run build
npm run test:basic-offline
```

`test:basic-weapons` 需要上面的开发服务，默认使用系统 `/usr/bin/chromium`。`GAME_URL` 可以指定生产预览地址。`test:basic-offline` 直接读取构建后的单文件，以内存提供 HTML，禁网验证四种武器及刷新存档。它不需要开发服务；当前环境浏览器禁止 `file://` 导航，因此没有用文件协议验证。

浏览器用例验证四种选择、自动攻击、键盘移动、手机双指瞬步、地面拾取、横竖屏、暂停、精确读档、旧存档转换与四种鉴赏模型。

规则测试包含四种基础武器的完整固定种子对局，仅提供正常移动、瞬步和收集输入，不修改生命、伤害、经验、时钟或随机流。历史武器规则测试保留用于内部兼容检查，不表示旧变体仍可选。历史浏览器脚本中的十五种选择与 Q 场景不作为本轮验收入口。

构建输出常规网页和 `dist/blade-evolution.html` 单文件离线版。离线文件自带图片与脚本，用现代浏览器打开即可。开发环境或 `?qa=1` 提供 `window.__BLADE__`、`advanceTime(ms)` 与 `render_game_to_text()` 供自动化验证；正常生产页面不暴露测试控制器。

## 主要代码

- `src/blade/config.ts`：当前四种选择、历史编号、数值、怪物与命中几何。
- `equipment.ts`、`simulation.ts`、`bows.ts`：独立攻击节奏、横扫与快斩、直线贯穿、自动单箭与确定性对局。
- `basic-weapon-art.ts`：四种普通武器造型与攻击姿态；`blade-model.ts`、`inspector.ts` 共用造型进行鉴赏。
- `ui.ts`、`style.css`、`main.ts`：开局、图鉴、HUD、输入与手机界面。
- `storage.ts`、`weapon-migration.ts`：存档读取与旧武器转换。
- `relics.ts`、`relic-loot.ts`、`food.ts`：现有道具、掉落和食物。

历史设计和验收仍在 `docs/`，原图和素材仍在 `art/` 与 `src/blade/assets/`。此前荒岛游戏位于 `/castaway.html`，其源码与存档独立，本轮未修改；说明见 [README-castaway.md](README-castaway.md)。备份方法见 [备份与恢复](docs/backup-and-restore.md)。
