# 刃之进化 / BLADE EVOLUTION

中文俯视割草游戏，普通刀、剑、弓、矛四种开局，十分钟一局。所有商店装备通用于四种武器，当前共有一件普通装备、三件稀有装备和三件史诗装备。

商店使用纵向升级树：共享的普通装备在上，三个稀有分支在中，对应的史诗装备在下，用线连接。图标在上、名字在下；普通背景为灰色、稀有为蓝色、史诗为紫色。打开商店暂停战斗，关闭继续，购物时间不计入十分钟。

本轮遵照玩家要求，未运行测试、试玩或独立类型检查，只打包网页与离线文件。历史报告及旧装备脚本保留其原有版本含义，不能代表当前版本。

## 装备与升级

| 品质 | 装备 | 本步支付 | 累计花费 | 属性 |
| --- | --- | ---: | ---: | --- |
| 普通 | 铁芯短刃 | 35 | 35 | 攻击力 +6 |
| 稀有 | 赤纹利刃 | +55 | 90 | 攻击力 +15、生命偷取 +6% |
| 稀有 | 鎏光锋刃 | +60 | 95 | 攻击力 +18、暴击率 +10% |
| 稀有 | 岩脊战刃 | +55 | 90 | 攻击力 +10、最大生命 +35 |
| 史诗 | 赤月誓刃 | +80 | 170 | 攻击力 +25、生命偷取 +12%、溢出治疗护盾 |
| 史诗 | 曜金裁决 | +85 | 180 | 攻击力 +30、暴击率 +20%、暴击倍率 +0.30 |
| 史诗 | 玄岩巨斧 | +85 | 175 | 攻击力 +15、最大生命 +70、生命附伤与裂岩溅射 |

三条路线：

- 铁芯短刃 → 赤纹利刃 → 赤月誓刃。
- 铁芯短刃 → 鎏光锋刃 → 曜金裁决。
- 铁芯短刃 → 岩脊战刃 → 玄岩巨斧。

只购买普通装备，稀有和史诗必须有直接前置装备才能补金币升级。升级消耗一件前置、在原位置替换，属性按新装备计算。史诗为终点，不再重复强化；每条路线最多持有一件稀有或史诗装备。可以购买多件短刃，分别走不同路线，总共最多占三个位置。

出售一件装备返还该件累计投入的 75%，向下取整，包含已消耗前置的花费。底部仅显示当前持有的装备图标，升级后同步替换。此前取消的其他装备与套装继续取消。

## 金币与节奏

普通怪金币掉率保持 **25%**，面额按种类为 1—5，精英必掉 25、首领必掉 100。金币必须走近拾取。开局武器此前降低的基础属性继续沿用。

前九分钟为怪潮，随后最多一分钟首领战。升级与首领登场不弹出装备选择，技能树暂不制作。圆润角色、深蓝描边和清晰高光继续保留。

## 存档与更新

按玩家新要求，**每次游戏更新直接清除旧存档，重新开局**，不迁移装备、退款或保留旧战绩。存储键保持为 `blade-evolution-save-v1`，当前结构 v14，并保存游戏内容版本。打包时根据割草游戏源码生成版本指纹；内容改变后的新版首次打开会删除旧存档，同一版本内仍正常保存与继续。

[当前设计](docs/gdd/blade-evolution-upgrade-tree-v2.0.md) · [升级图示](docs/images/equipment-upgrade-tree.svg) · [备份说明](docs/backup-and-restore.md)。[原网页试玩](https://jess161.github.io/codex-/) 与源码分支分别更新，本轮未发布 Pages。

开发需要 Node.js 20.19+ 或 22.12+。`npm ci` 安装依赖，`npm run dev -- --port 4173` 启动开发服务器。常规 `npm run build` 包含类型检查；本轮仅使用 Vite 资源打包及 `scripts/standalone.mjs` 生成自带资源的单文件游戏，按要求没有执行测试或试玩。

当前装备定义在 `src/blade/gear.ts`，升级替换在 `simulation.ts`，商店树在 `ui.ts`。荒岛游戏源码保持独立。
