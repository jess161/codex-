# 刃之进化 / BLADE EVOLUTION

中文俯视割草游戏，普通刀、剑、弓、矛四种开局，十分钟一局。商店目前只保留三件史诗装备：赤月誓刃、曜金裁决、玄岩巨斧。全部通用于四种武器，图标统一使用紫色史诗背景。

商店保持图标在上、名字在下；点击查看属性，再购买、升级或出售。打开商店暂停战斗，关闭后继续，购物时间不计入十分钟。战场底部只显示已获得的装备图标。

本轮遵照玩家要求，未运行测试、试玩或独立类型检查，只打包网页与离线文件。历史验收报告及旧装备脚本保留其原有版本含义，不能代表当前三件史诗版本。

## 三件史诗装备

| 装备 | 一级价格 | 一级属性与特点 |
| --- | --- | --- |
| 赤月誓刃 | 170 | 攻击力 +25、生命偷取 +12%；溢出吸血转为临时护盾 |
| 曜金裁决 | 180 | 攻击力 +30、暴击率 +20%、暴击倍率 +0.30 |
| 玄岩巨斧 | 175 | 攻击力 +15、生命 +70；生命附伤与目标周围溅射 |

每件最高三级，升级不占新位置；最多持有三种装备。升级价格为基础价格 + 当前装备等级 ×35。出售整件返还累计购入价的 75%，向下取整。所有其他商店装备已取消，包括闪电连锁、其他攻击装、防御装和足具；没有流派分类、推荐出装或套装凑件奖励。

## 金币与节奏

普通怪金币掉率从 60% 降至 **25%**；面额仍按种类为 1—5，精英必掉 25、首领必掉 100。金币必须走近拾取，未掉金币的击杀仍获得经验。开局武器此前降低的基础属性继续沿用。

前九分钟为怪潮，随后最多一分钟首领战。升级与首领登场不弹出装备选择，技能树暂不制作。圆润角色、深蓝描边和清晰高光继续保留。

## 操作

| 动作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 拖动摇杆 |
| 攻击 | 自动瞄准攻击 | 同左 |
| 瞬步 | 空格 / 点击战场 | 瞬步按钮 |
| 商店 | B / 商店图标 | 商店图标 / 已购装备 |
| 查看属性 | 点击史诗装备图标 | 同左 |
| 继续战斗 | 关闭商店 / B / Esc | 关闭 / 继续战斗 |
| 暂停 | Esc / P | 右上暂停 |

打开和关闭商店都会清除旧移动与瞬步输入。存档、金币与装备在暂停中保留。

## 存档与备份

存储键为 `blade-evolution-save-v1`，当前结构 v13。v10—v12 的旧商店按当时的目录和价格独立读取，保留三件史诗装备及等级，移除其他装备并一次性退回仍持有装备的购入花费。退款从累计消费中撤销，不重复发放，也不再次补偿已经出售的装备。保留生命比例、等级、世界、金币、战绩和血契护盾，清除已移除装备的触发状态。

[当前设计](docs/gdd/blade-evolution-epic-trio-v1.9.md) · [备份说明](docs/backup-and-restore.md)。[原网页试玩](https://jess161.github.io/codex-/) 与源码分支分别更新，不能代表当前版本已发布。

开发需要 Node.js 20.19+ 或 22.12+。`npm ci` 安装依赖，`npm run dev -- --port 4173` 启动开发服务器。常规 `npm run build` 包含类型检查；本轮仅使用 Vite 资源打包及 `scripts/standalone.mjs` 生成自带资源的单文件游戏，按要求没有执行测试或试玩。

当前装备定义在 `src/blade/gear.ts`，旧商店数据仅由 `retired-shop-state.ts` 用于读取和退款，已退出实际装备结算及展示。荒岛游戏保持独立。
