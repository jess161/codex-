# 刃之进化 / BLADE EVOLUTION

选择你的刀，斩出自己的路。中文 2D 俯视割草肉鸽，当前保留平行名刀成长 v0.5，怪物与刀具鉴赏补充 v0.6，被动道具组 v0.7，以及按历史对话重建的完整玩法 v0.8。每局重新从 Lv.1 成长，10 分钟生存后挑战圆甲暴君，首领战最多 90 秒。

本次 v0.8 是根据历次需求重新实现，不能视为找回丢失源码；见 [重建清单](docs/reconstruction-latest.md)。

## 立即游玩

构建后的 **`dist/blade-evolution.html` 是单文件离线版**，下载后用现代浏览器打开即可，不需要账号、API Key、网络图片或安装依赖。手机也可通过部署后的网页游玩。存档保存在当前浏览器和访问地址下，不跨设备同步。

开发运行需要 Node.js 20.19+ 或 22.12+：

```bash
npm ci
npm run dev -- --port 5173
```

打开开发服务首页。此前的第一人称荒岛游戏保留在 `/castaway.html`，其代码和存档独立，说明见 [README-castaway.md](README-castaway.md)。

## 一局之中

- 开局 12 把刀全部可选，每把对应独立流派与故事被动，本局始终使用所选刀。名刀不设跨作品实力排名，图鉴按来源陈列。
- 初识 Lv.1 → 磨合 Lv.6 → 熟练 Lv.12 → 共鸣 Lv.20 → 觉醒 Lv.28。每个掌握阶段至少实战 75 秒，其他等级正常升级；多余经验储存，菜单不计时。
- Lv.1—30，累计经验 2770；每级一次被动道具三选一，共 29 次。普通升级恢复 1 生命，掌握进阶恢复 4 生命，战斗和时钟暂停。
- 四组十二件道具：铸刃、疾风、灵能、灵护。每次随机三件不同选项，只能选一件；重复获得时升级，每件最多四级。集齐同组两件、三件不同道具解锁组合，满级道具不再出现。原锻造目录和分类标签已移除。
- 后期刀身可夸张增大，实际范围最多 420；刀柄独立绘制，维持可握持大小。大刀增加起步转向惯性、蓄力和收刀负担；角色随负重前倾、流汗、双手握刀，轻羽与疾风组合改善操控。
- 轻羽按比例减重，不产生负重量。道具卡片显示真实前后数值，HUD 显示尺寸与负重；松手立即停止，重刀的瞬步仍可靠移动 140。
- 故事被动始终属于所选刀，并随掌握强化：寒霜控场、护刃反击、扇形刀气、灼烧传火、瞬步月牙等各有特点。图鉴展示原作背景、取意与五阶段效果。
- 同一把刀逐步增加刀光层次、光环与元素装饰，镜头为巨刃略微拉远。危险弹丸与预警保持在特效上方。
- 怪群从每秒 0.9 次生成尝试逐渐增加，第 4 分钟后加速增密，后期约 10.8 次；标准容量逐渐升至 280，轻量升至 180。吐弹者仍限 6 只，经验球逐个保留原来的掉落位置，不合并、不设数量上限；只创建视野内的贴图，保存和首领转换均保留。
- 十二种普通形态、四轮精英与 10 分钟后的圆甲暴君。裂壳母团 / 幼团、赤角冲兽、游灯幽魂、针背刺团保留；另有 3:30 登场的毒气泡团、5:00 登场的爆燃球和 7:00 登场的隐纹幽球，均有预警与反制窗口。首领保留冲锋、缺口震荡波和召唤，90 秒内击败。
- 未挥砍时刀面约 45° 斜向拖地、视觉收窄到约四分之一；惯性随移动、转向和负重变化，挥砍时展开。刀尖留下与刀同色的淡出痕迹，金白火花随刀长和刀宽放大，不播放地面摩擦声。
- 命中分为轻、实、重、清群四档，短停顿最大 45ms、镜头偏移最大 2.7 CSS 像素；有伤害数字、受击压缩、死亡散开和一刀多杀提示。动态、停顿、震屏和默认关闭的触感可分别设置。
- 刀的专属被动随刀身尺寸成长：刀气、月牙的弧形、碰撞宽度和射程同步增加；月轮、狮吼、传火及护刃反击的实际范围与显示边界使用同一组尺寸。护盾和触发特效同步放大，已飞出的刀气保留释放时尺寸；旧 v6 存档可继续使用。技能尺寸与验证见 [被动缩放验收](docs/blade-passive-size-verification.json)。
- 按 C 或点击 HUD 星形按钮查看战斗力；每把刀单独以初始 1,000 为基准，按输出 45%、清群 25%、机动 20%、生存 10% 的几何加权展示成长，不用于跨刀型排名。
- 六种随时可换的战场：几何训练场、微风草原、暮金沙海、青石遗迹、星夜幻境、经典点阵。默认世界固定网格，便于辨认移动。战场按设备像素密度绘制，最多 3 倍；轻量画面最多 1.5 倍，画布总量受 800 万像素预算限制。
- 每局重置等级、掌握与道具，保留名刀试用记录、成就与战绩。任意刀觉醒解锁曙光色，五次试炼解锁星紫色。

道具数值、组合、美术与迁移见 [被动道具组三选一 v0.7](docs/gdd/blade-evolution-relics-v0.7.md)。历史成长规则见 [平行名刀与巨刃锻造设计 v0.5](docs/gdd/blade-evolution-routes-v0.5.md)，新增内容见 [怪物、刀具鉴赏与受伤声 v0.6](docs/gdd/blade-evolution-bestiary-atelier-v0.6.md)。

图鉴刀图可点击“旋转鉴赏”：鼠标或单指自由旋转，滚轮 / 双指缩放，支持转台、复位、键盘操作和直接换刀。设备支持时展示带厚度与倒角的立体模型，弱设备保留平面旋转。刀具、角色和怪物共用圆润糖果色、深蓝轮廓与简洁高光；鉴赏模型沿用实战贴图的真实轮廓。鉴赏时战斗保持暂停。怪物志展示各类敌人的登场与应对。

## 操作

| 动作 | 电脑 | 手机 |
| --- | --- | --- |
| 战斗力 | C / HUD 星形按钮 | HUD 星形按钮 |
| 移动 | WASD／方向键 | 在战场任意位置按下并拖动 |
| 普攻 | 靠近后自动挥砍 | 同左 |
| 瞬步 | 空格／点击战场 | 右下瞬步按钮 |
| 道具三选一 | 点击／1—3 | 点击卡片 |
| 随身道具 | I／战场道具按钮／暂停菜单 | 战场道具按钮／暂停菜单 |
| 暂停 | Esc／P／右上暂停 | 右上暂停 |
| 全屏 | F／首页全屏按钮 | 浏览器支持时可用 |

瞬步沿最近移动方向，默认朝上；140 单位位移，5 秒冷却，起始 0.12 秒无敌。升级、暂停、菜单与切后台都阻止战斗输入残留。左右手触控可同时操作。

手机采用全屏浮动摇杆：在战场任意位置按下，摇杆在指尖出现；朝想移动的方向拖动，松手后停止并隐藏摇杆。第一根手指控制移动，另一根手指可同时点击瞬步或暂停；菜单与按钮保持独立操作。取消触摸、切后台、窗口变化和进化选择都会清除移动输入。

声音在点击开始后解锁，可随时静音；设置提供减少动态、关闭震屏和轻量画面。音效由 Web Audio 在本地合成。怪物受伤声分为八类音色，真实受击与致命一击触发；自动限制叠音。设置中的“怪物受伤声”可独立关闭，总声音开关仍控制全部音效。

在**首页右上角设置**，或**暂停 → 游戏设置 → 战场主题**中，可查看六种地面的预览并选择。选择立即生效，刷新后仍保留。全部主题免费使用，仅改变视觉，不添加障碍或改变怪物、伤害、掉落与随机状态；星夜主题同时调整 HUD 和深色怪物的轮廓对比。

## 存档

`blade-evolution-save-v1` 与荒岛存档分开。每 5 秒、暂停、进化选择、切后台与结算时保存；可从首页继续未完成的同一局。保存完整的敌人、掉落、弹丸、首领、随机状态、道具等级和待选项，读档不重新抽取选项。死亡或胜利后不提供回档继续。新局选刀界面会提示出发后替换未完成对局，返回可继续保留旧局。

当前结构为 v6，保留原存储键。新增道具等级、闪电充能和泡泡盾状态。v1—v5 可迁移，保留原名刀、旧锻造数值、生命、经验、故事被动与永久记录；旧待选锻造只在首次迁移时固定转换为三件道具，不消耗随机数。之后的 v6 待选项与随机状态原样恢复。

不兼容的对局存档会提示，并尽量保留永久图鉴与战绩。无痕模式或浏览器禁用存储时，游戏会提示无法保存。

```bash
npm run build
npm test
# 保持开发服务运行：
npm run test:browser
# 验证道具三选一、十二件美术、组合、存档、手机与 WebGL（预览端口 4173）：
npm run test:relics
# 验证重建版拖刀、经验球、特殊怪物、打击反馈、战斗力、DPR 和 WebGL（4173）：

# 验证立体鉴赏、手机旋转缩放、怪物行为、受伤声和回退：
npm run test:atelier
# 验证十二种故事被动、状态特效、图鉴、蓄势读档与触控：
npm run test:passives
# 验证慢成长、尺寸、负重、表情、操控与道具预览：
npm run test:weight
# 验证十二种平行流派、29 次道具选择、介绍与手机排版：
npm run test:growth
# 验证全屏浮动摇杆、双指与触摸中断：
npm run test:touch
# 验证地面选择、滚动与存档兼容：
npm run test:themes

npm run preview
npm run test:offline
```

`npm run build` 输出常规多页面部署目录，并额外生成两个独立的单文件离线游戏。默认使用 Phaser Canvas 渲染，不要求 WebGL；添加 `?renderer=webgl` 可选择 WebGL 路径。

规则测试覆盖扇形多目标、刀气去重、五个掌握阶段、29 次道具选择、尺寸上限、比例减重、瞬步与惯性、故事被动强化、特殊敌人控制边界、五千颗独立经验球、怪潮容量、快照和首领。十二把刀各有一局固定种子的完整对局，仅使用正常移动、瞬步与道具选择，不修改生命、伤害、经验或时钟；验证同一把刀可成长通关，阶段练刀计时有效。这是自动化可达性验证，不代表真人难度测试。

浏览器测试使用系统 `/usr/bin/chromium`（`CHROMIUM_PATH` 可覆盖），验证真实键鼠与双指触控、暂停、道具选择、读档、图鉴、重开和结束状态。经验进度、高密度竞技场和终局验证使用明确标注的测试场景，避免把大量等待时间计为测试。截图和报告位于 `test-results/blade/`。`GAME_URL` 可覆盖目标地址。

开发环境或显式 `?qa=1` 提供 `window.__BLADE__`、`advanceTime(ms)` 与 `render_game_to_text()`，用于自动化测试。正常生产页面不暴露测试控制器。

## 美术与结构

重建美术原图、裁切与锚点记录保留在 `art/reconstructed/`。圆润球形角色、十四种怪物和经验球使用统一的 512×512 无损 WebP 帧；十二把糖果色刀具使用 1280×512 无损图集，刀身与握柄共用一张贴图。刀背和鉴赏模型的轮廓从同一张贴图的透明边缘提取。运行时通过旋转、投影、受击压缩与粒子产生动作，不是逐帧动画。道具原图及图标保留在 `art/blade-relics/` 与 `src/blade/assets/relics/`。

- `src/blade/config.ts`：十二种平行刀型、掌握阶段、作品介绍、怪物、旧锻造兼容数据、经验、命中规则和成就。
- `src/blade/blade-art.ts`：十二柄糖果色刀具的共享贴图、配色与锚点。
- `src/blade/monster-art.ts`：球形角色、十四种怪物与经验球的无损素材。
- `src/blade/blade-drag.ts`、`blade-back.ts`：移动惯性、45° 投影、实际刀尖、刀痕与火花预算。
- `src/blade/display.ts`、`grounds.ts`：设备像素密度、六种清晰地面与纹理缓存。
- `src/blade/feedback.ts`、`power.ts`：命中反馈分档、可读战斗力。
- `src/blade/threats.ts`：三种特殊怪物的参数与隐身显示规则。
- `src/blade/inspector.ts`、`blade-model.ts`：自由旋转鉴赏、立体模型与资源释放。
- `src/blade/monster-voices.ts`：八类怪物受击音色与本地合成。
- `src/blade/passives.ts`：十二个被动、故事取意、状态与 HUD 进度。
- `src/blade/equipment.ts`：尺寸、负重、移动与挥刀阶段的统一数值。
- `src/blade/relics.ts`、`relic-art.ts`：四组十二件被动道具、组合、等级、图标和旧选项映射。
- `src/blade/simulation.ts`：确定性战斗、空间网格、怪物 AI、波次、首领、升级与可序列化状态。
- `src/blade/scene.ts`：Phaser、精灵池、挥刀、刀光、预警、伤害数字与镜头。
- `src/blade/main.ts`：固定步长、输入、暂停、音效与界面连接。
- `src/blade/ui.ts`、`style.css`：中文首页、HUD、道具选择、图鉴、设置与结算。
- `src/blade/storage.ts`：永久数据与有效对局保存。
- `src/blade/audio.ts`：程序合成音效。
- `scripts/prepare-reconstructed-assets.py`：复现本次美术裁切、尺寸归一、透明轮廓和锚点，需要 Pillow；历史素材处理脚本保留。
- `docs/gdd/blade-evolution-gdd-v0.1.md`：原始设计文档。
- [十二阶名刀成长补充设计 v0.2](docs/gdd/blade-evolution-growth-v0.2.md)：历史版本与作品介绍。
- [慢成长与尺寸负重设计 v0.3](docs/gdd/blade-evolution-growth-v0.3.md)：历史慢成长与动作设计。
- [故事被动设计 v0.4](docs/gdd/blade-evolution-passives-v0.4.md)：故事取意与被动的初版规则。

标准档敌人容量从 100 增到 280，弹丸 32、装饰粒子 280；轻量敌人从 72 增到 180，弹丸 24、粒子 100。经验球均不设数量上限，远离吸取范围时保持坐标，视野之外不创建精灵。刀痕标准/轻量最多 320/112 段，火花 40/14 个；地面危险区最多 12/8 个，其中毒气最多 6/4 个。危险弹丸和预警始终位于装饰效果之上。

本次验收见 [重建版验收记录](docs/blade-reconstruction-verification.json)，提交和备份恢复方法见 [源码备份说明](docs/backup-and-restore.md)。
