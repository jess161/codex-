# 刃之进化 / BLADE EVOLUTION

中文 2D 俯视割草游戏。普通 **刀、剑、弓、矛** 四种开局；当前版本取消旧装备与套装，改为打怪掉金币、走近拾取、购买三类通用装备。**前九分钟怪潮，最后最多一分钟首领，总时限十分钟。** 不做技能树，不强制弹出升级选择。

商店随时开启，战斗继续，购买立即生效。底部只显示已获得装备的图标与小等级标记，可左右滑动。美术沿用圆润糖果色、深蓝描边和清晰高光。

源码更新与网页部署分开：[上次发布的试玩](https://jess161.github.io/codex-/) 不等于当前源码已上线。当前规则见 [金币与通用装备设计](docs/gdd/blade-evolution-economy-v1.3.md)。

## 四种手感

| 武器 | 基础攻击 | 特点 |
| --- | --- | --- |
| 刀 | 横扫 | 170° 宽扇形，前方多目标 |
| 剑 | 快斩 | 76° 窄幅，短准备与收势，高频攻击 |
| 弓 | 自动射击 | 自动瞄准可见目标，一次一箭，首个命中后消失 |
| 矛 | 直线贯穿 | 恒宽直线贯穿，刺出前跟随目标瞄准，侧后方不扫到 |

## 三类通用装备

| 类别 | 装备 | 每级效果 |
| --- | --- | --- |
| 防御 | 果冻护心 / 泡泡护甲 / 蜜露护符 | 生命 +20 / 减伤 6% / 每五秒回血 2 |
| 攻击 | 星糖晶核 / 发条握柄 / 聚能透镜 | 基础伤害 +18% / 攻击间隔和动作 ×0.92 / 攻击距离 +12% |
| 足具 | 疾风短靴 / 弹簧步靴 / 拾光长靴 | 移速 +7% / 瞬步冷却 −0.4 秒 / 金币经验吸取范围 +18% |

每件最高五级，全部可同时拥有，独立生效，没有套装条件。伤害作用于横扫、快斩、普通箭及每个矛贯穿目标；攻速同步加快动作；距离同时影响索敌和实际命中 / 射程。九件装备在四种武器上的效果均有真实模拟行为测试。

普通怪按种类掉 1—5 金币，精英 25、首领 100，金币留在击杀位置，必须走近拾取。经验与回血食物继续独立掉落。首领的金币为终局地面掉落，不会自动记账。本局金币与装备在下一局重置，永久战绩和成就保留。

## 操作

| 动作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 按住战场拖动浮动摇杆 |
| 攻击 | 自动瞄准与攻击 | 同左 |
| 瞬步 | 空格 / 点击战场 | 瞬步按钮，可和移动双指并用 |
| 拾取 | 走近金币、经验与食物 | 同左 |
| 商店 | B / 金币旁的商店按钮 | 商店按钮 / 已购装备图标 |
| 已购装备 | I / 暂停菜单 | 暂停菜单 |
| 战斗力 | C / HUD 星形按钮 | HUD 星形按钮 |
| 暂停 | Esc / P；商店开启时 Esc 先关商店 | 右上暂停 |

升级、购买、首领登场均不强制暂停或清除移动手势。主动打开暂停 / 设置 / 图鉴和切后台才暂停。金币实时更新不会打断正在按下的购买按钮，手机兼容一指移动、另一指购买。

## 存档

沿用 `blade-evolution-save-v1` 键，新结构 v9，兼容读取 v1—v8。旧装备与锻造折算为本局金币，旧地面道具转换成原地金币；旧套装和旧武器附加效果不再继续生效。等级、经验、世界与永久战绩保留；旧时长按进度比例映射到新版十分钟时限，生命保留比例。每份旧存档只转换一次。

新版保存余额、累计收入 / 花费、装备等级与获取顺序、回血计时、经验、食物、金币、敌人和在飞箭矢。验证收支守恒和购买总价，拒绝损坏数据。每五秒、购买、暂停、切后台和结算保存。

## 开发与验证

需要 Node.js 20.19+ 或 22.12+：

```bash
npm ci
npm run dev -- --port 4173
# 另一个终端：
npm test
npm run test:economy
npm run build
npm run test:offline
```

浏览器测试默认使用系统 `/usr/bin/chromium`，`GAME_URL` 可指定生产预览地址。`npm run test:browser`、`test:basic-weapons` 和 `test:loot` 也指向当前金币装备验收。旧变体和套装浏览器脚本仅作历史参考。

规则测试保留历史数据兼容检查，并包含四种当前武器的完整固定种子对局：只用移动、瞬步、拾取和正常购买，不修改 HP、伤害、经验、时钟或随机流。手机浏览器测试是触控模拟，不是实体设备性能测试。

构建生成常规网页与 `dist/blade-evolution.html` 单文件离线版，所有资源内嵌。离线检查将实际 HTML 字节放入内存页面并禁用网络；当前环境浏览器禁止 `file://` 导航，因此未宣称测试过手机文件管理器。开发环境或 `?qa=1` 提供 `window.__BLADE__`、`advanceTime(ms)` 与 `render_game_to_text()` 用于测试，正常生产页面不暴露 QA 控制器。
