# 刃之进化 / BLADE EVOLUTION

中文俯视割草游戏，当前只选择 **胡萝卜剑** 或 **香蕉弓**，十分钟一局。胡萝卜剑固定作 **45° 横扫**，香蕉弓的实际射程固定为 **140**，自动瞄准并射出瓜子箭。剑与矛已退出开局、图鉴和新对局启动入口。

胡萝卜剑现按玩家提供的参考图重制：**叶冠、缠带握柄、金橙色护手、萝卜徽章、收尖的分节剑身**。保留游戏的深蓝描边、圆润体积与清晰高光，战斗、菜单与图鉴使用同一张新图，立体鉴赏读取它的透明轮廓。实际三次调用图片生成工具制作中性剑图及新剑的火毒、电纹材质，来源见 `art/carrot-sword/`。

香蕉弓继续使用玩家选定的 **A 组原画**，黄色果身、深色果蒂、奶色绳结、绿色握带与弓弦锚点保留。[A 组选稿](docs/images/a-group-approved.png) · [历史素材说明](docs/art/approved-a-art-direction.md)

商店现为 **电、火、毒调料罐头**，同时适用于两种武器：一个共同普通罐，三个稀有分支，对应三个史诗罐。七张实际图标经图片生成工具制作，透明素材与来源记录保留在 `art/seasonings/`。所有怪物死亡必掉金币，装备价格沿用上一版。

胡萝卜剑保持完整正面和普通持剑姿态，不恢复固定 45° 贴地投影。起手仍为小尺寸，一级握点到剑尖 48.8、整体命中距离 64.8；横扫仍为 45°。香蕉弓仍为原有小尺寸，射程 140。不附元素时保留约 1.1 秒橙色刀痕，线宽随当前武器改变，暂停冻结、重开清空。

商店使用纵向升级树：共享的普通装备在上，三个稀有分支在中，对应的史诗装备在下，用线连接。图标在上、名字在下；普通背景为灰色、稀有为蓝色、史诗为紫色。打开商店暂停战斗，关闭继续，购物时间不计入十分钟。

本轮遵照玩家要求，未运行测试、试玩或独立类型检查，只打包网页与离线文件。历史报告及旧装备脚本保留其原有版本含义，不能代表当前版本。

## 装备与升级

| 品质 | 装备 | 本步支付 | 累计花费 | 属性 |
| --- | --- | ---: | ---: | --- |
| 普通 | 小调味罐 | 35 | 35 | 攻击力 +6 |
| 稀有 | 麻椒粉 | +55 | 90 | 攻击力 +10；每 5 次普攻释放 55% 攻击力连锁闪电 |
| 稀有 | 辣椒酱 | +60 | 95 | 攻击力 +10；燃烧 3 秒，每半秒 8%；死亡爆燃 45%，范围 55 |
| 稀有 | 幽绿菇酱 | +55 | 90 | 攻击力 +10；每层毒每半秒 3.5%，持续 4 秒，最多 5 层 |
| 史诗 | 雷鸣椒盐罐 | +80 | 170 | 攻击力 +20；每 4 次普攻释放 85% 攻击力连锁闪电 |
| 史诗 | 火山辣酱罐 | +85 | 180 | 攻击力 +20；燃烧 3 秒，每半秒 14%；死亡爆燃 80%，范围 75 |
| 史诗 | 翠毒蘑菇罐 | +85 | 175 | 攻击力 +20；每层毒每半秒 6%，持续 5 秒，最多 5 层 |

三条路线：

- 小调味罐 → 麻椒粉 → 雷鸣椒盐罐。
- 小调味罐 → 辣椒酱 → 火山辣酱罐。
- 小调味罐 → 幽绿菇酱 → 翠毒蘑菇罐。

只购买普通装备，稀有和史诗必须有直接前置装备才能补金币升级。升级消耗一件前置、在原位置替换，属性按新装备计算。史诗为终点，不再重复强化；每条路线最多持有一件稀有或史诗装备。可以购买多个调味罐，分别走不同路线，总共最多占三个位置，电火毒可以同时生效。

闪电按每次挥刀或放箭充能，挥空也计数，一刀命中多怪仍只计一次；从 4 个不同目标起，Lv.8、15、22、29 各加 1 个，最多 8 个，单次链不重复目标。火焰重复命中刷新 3 秒；燃烧目标被普攻或自身燃烧击败时爆燃。毒重复命中叠层并刷新持续时间，精英和首领额外承受 25% 毒伤。燃烧、毒、闪电与爆燃均不触发新的普攻元素，爆燃不会继续连爆。

胡萝卜现在会随实际装备显示分区材质：**电纹叶柄、毒液刀身、炽红根尖**，待机可见，三种可同时出现。稀有升史诗后材质和毒滴／火苗／电光更明显；火为主挥砍弧，毒甩绿滴，地面分别留绿色气泡痕、快速熄灭的余烬和短电痕。本轮以新剑图重新制作材质并对齐元素与拖痕锚点，素材见 `art/carrot-sword/`；此前粗萝卜版本保留在 `art/carrot-elements/`。按玩家选择，冰只准备覆霜叶柄素材，本轮不增加冰装备或减速玩法。

出售一件装备返还该件累计投入的 75%，向下取整，包含已消耗前置的花费。底部仅显示当前持有的装备图标，升级后同步替换。此前取消的其他装备与套装继续取消。

## 金币与节奏

普通怪金币掉率为 **100%**，面额按种类为 1—5，精英必掉 25、首领必掉 100。爆燃球自爆也掉金币；金币仍需走近拾取。开局武器此前降低的伤害与攻击速度继续沿用，胡萝卜剑随本轮缩小进一步缩短命中距离。

前九分钟为怪潮，随后最多一分钟首领战。升级与首领登场不弹出装备选择，技能树暂不制作。圆润角色、深蓝描边和清晰高光继续保留。

## 存档与更新

按玩家新要求，**每次游戏更新直接清除旧存档，重新开局**，不迁移装备、退款或保留旧战绩。存储键保持为 `blade-evolution-save-v1`，当前结构 v15，并保存游戏内容版本。打包时根据割草游戏源码生成版本指纹；内容改变后的新版首次打开会删除旧存档，同一版本内仍正常保存与继续。
