# 刃之进化 / BLADE EVOLUTION

中文 2D 俯视割草游戏，普通刀、剑、弓、矛四种开局。当前装备设计参考《英雄联盟》的出装思路：**十八件原创装备、六件位置、足具限一件**，让装备收益自然配合、自由混搭。商店入口使用透明描边图标；打开后是竖向装备目录，图标在上、名字在下，点选后查看属性并购买、升级或出售。打开商店暂停战斗，关闭后继续；战场底部只显示已购图标，支持左右滑动。

保留打怪掉金币、走近拾取、前九分钟怪潮和最后最多一分钟首领战。糖果色、深蓝描边与清晰高光继续沿用；没有技能树和强制三选一。

源码与网页部署分别更新：[此前发布的网页](https://jess161.github.io/codex-/) 不代表当前源码已上线。新装备见 [三件攻击装备](docs/gdd/blade-evolution-three-relics-v1.8.md)，界面见 [竖向装备商店](docs/gdd/blade-evolution-vertical-shop-v1.6.md)，数值调整见 [暂停商店与开局平衡](docs/gdd/blade-evolution-shop-balance-v1.5.md)。

本轮按玩家要求未运行测试、试玩或独立类型检查，只生成离线发行文件。历史验收报告记录的是各自当时的版本。

## 装备搭配

商店默认展示全部十八件装备，只按“全部、防御、攻击、足具”筛选。没有流派分类、推荐高亮、预设出装或自动流派标签。图标下直接显示名称与价格，点选后在固定详情区查看属性、购买、升级和出售。

暴击率与暴击倍率、攻速与普攻特效、吸血与治疗增幅、最大生命与灼烧护盾、受击反伤与恢复可以自然配合，也可以交叉搭配。没有套装凑件奖励。

十八件装备分为防御五件、攻击十件、足具三件；每件最高三级，升级不占新位置。出售返还实际累计购入价的 75%，可以腾出位置或更换鞋子。

## 四种基础攻击

| 武器 | 手感 |
| --- | --- |
| 刀 | 宽幅扇形横扫，前方多目标 |
| 剑 | 窄幅快速斩击，准备与收势短 |
| 弓 | 自动瞄准，一次一箭，命中首个敌人后消失 |
| 矛 | 前方恒宽直线贯穿，刺出前跟随目标瞄准 |

开局基础伤害基数从 20 降到 13，攻击间隔增加 10%，攻击距离缩短 10%；等级成长和装备机制保留，剑仍是最快的武器。选武器页和图鉴显示调整后的实际间隔与距离。

新增三件通用攻击装备：**赤月誓刃**（170 金币，攻击力 +25、生命偷取 +12%，溢出治疗积累血契护盾）、**曜金裁决**（180 金币，攻击力 +30、暴击率 +20%、暴击倍率 +0.30）、**玄岩巨斧**（175 金币，攻击力 +15、生命 +70，普攻附加最大生命伤害并向命中处周围溅射）。数值为一级，每件最高三级，六件位置和一个足具位继续保留。三张图标重新设计为赤红弯刃、金色裁决重剑和玄岩巨斧。

新增攻击装备 **闪电连锁**（150 金币）：一级提供固定攻击力 +20、攻速 +15%。每次有效普攻蓄能 20，蓄满 100 后下一次命中释放连锁闪电；英雄等级提升后最多命中 4—8 个不同目标，每跳伤害递减 10%。横扫和贯穿每轮只蓄能一次，装备伤害不再次充能。HUD 与已购图标显示盈能。

所有装备通用。刀剑、箭矢和矛均能暴击、吸血、附加当前生命伤害和触发电击。横扫和贯穿每轮只计一次热力 / 电击，防止多目标无上限叠层。装备伤害不再次触发普攻特效；首领附伤和吸血均有明确上限。

护盾、灼烧、反伤、闪电和瞬步强化有对应视觉，HUD 显示热力、护盾与强化状态。金币和经验保留世界坐标，必须走近拾取。普通怪以 60% 概率按种类掉 1—5 金币，精英必掉 25、首领必掉 100；金币与装备仅在本局生效。

## 操作

| 动作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 按住战场拖动摇杆 |
| 攻击 | 自动瞄准与攻击 | 同左 |
| 瞬步 | 空格 / 点击战场 | 瞬步按钮，可与移动双指操作 |
| 商店 | B / 金币旁的商店按钮 | 商店按钮 / 已购图标 |
| 出售换装 | 商店中点“出售”，再购买新装备 | 同左 |
| 查看属性 | 点商店中的装备图标 | 同左 |
| 已购装备 | I / 暂停菜单 | 暂停菜单 |
| 暂停 | Esc / P；商店开启时 Esc 先关商店 | 右上暂停 |

商店打开后冻结敌人、攻击、金币、回血、护盾、冷却和战斗时间。购买、出售和升级都在暂停中进行；关闭商店继续战斗。开店和关店都会清除原有移动、瞬步和摇杆输入，避免误操作。正常升级与首领登场不弹出选择，商店时间不计入十分钟。

## 存档

沿用 `blade-evolution-save-v1` 键，本版结构 v12。v10/v11 的装备、金币、顺序、触发计时与世界原样保留，只补入未购买的新装备及血契护盾字段。v9 的九件数值装备使用旧价格独立验证，已花装备金币全额返还，方便重新出装；保留等级、时钟、世界、地面金币、生命比例和战绩，补偿不重复。更早版本继续按历史规则转换。

新档保存余额、购买与出售记录、六件顺序与等级、热力、护盾、闪电计数、连锁盈能、血契护盾、回血窗口、冲刺强化、敌人和箭矢。校验金币守恒、位置与鞋子限制，拒绝异常等级和战斗计时。每五秒、购买、出售、暂停、切后台和结算时保存。

## 开发与验证

需要 Node.js 20.19+ 或 22.12+：

```bash
npm ci
npm run dev -- --port 4173
# 另一个终端：
npm test
npm run test:item-builds
npm run test:chain-lightning
npm run build
npm run test:offline
```

当前浏览器测试默认使用 `/usr/bin/chromium`，`GAME_URL` 可以指定生产预览地址。`test:browser`、`test:economy`、`test:basic-weapons`、`test:loot` 也指向本版验收。历史旧装备、旧套装与变体浏览器脚本只作历史参考。

完整固定种子对局覆盖“六组测试搭配 × 四种武器”，只提供正常移动、瞬步、捡金币和购买输入，不改生命、伤害、经验、时间或随机数。金币调低后要求各路线仍能购买核心装备，允许以四至六件结束，六件为容量上限。另有机制、掉落与未掉落、出售、六件、换鞋、暂停、存档与迁移检查。手机浏览器为触控模拟，不是实体设备性能测试。

构建生成常规网页和 `dist/blade-evolution.html` 单文件离线版，所有资源内嵌。离线检查将实际 HTML 字节放到内存页面并关闭网络；当前环境浏览器禁止 `file://` 导航，未宣称测试过手机文件管理器。开发或 `?qa=1` 提供 QA 控制器，正常生产页不暴露它。

代码位于 `src/blade/`：`gear.ts` 定义装备与金币，`build-state.ts` 保存战斗触发状态，`build-art.ts` 绘制特效，`simulation.ts` 负责真实结算，`legacy-gear.ts` 验证旧九件目录。设计历史保留在 `docs/`；[备份说明](docs/backup-and-restore.md) 记录恢复方式。荒岛游戏保持独立，本轮未修改。
