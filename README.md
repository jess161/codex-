# 刃之进化 / BLADE EVOLUTION

Phaser 3.90 + TypeScript 手机浏览器割草游戏，十分钟一局。新局固定一把胡萝卜剑，通过六次三选一组合主形态、攻击变异、元素和终极觉醒；经验、金币拾取和调料罐头商店继续沿用。

- 主形态：巨剑、双刃、剑气三选一，本局锁定。
- 首批变异：连续斩击、穿透剑气，最多两种；穿透需要剑气能力。
- 元素：火、冰、毒、雷中最多三种；商店罐头和附魔共用元素槽，同元素可升至Ⅱ级。
- 元素融合：六种双元素反应，以及可作用于任意形态的火冰毒三灾组合；每种反应有整把武器共享冷却。
- 首批觉醒：三灾与万剑，每局最多一种，条件不足时提供有效强化。其余两种变异与四种觉醒保留禁用配置供后续扩展。

普通成长保留收经验自动升级，不暂停；每 27 秒放行一档等级，10 分钟最多 20 次升级至 Lv.21，自动强化伤害、攻速、尺寸与暴击。重要成长在 1:00、2:30、4:00、5:30、7:00、8:30 暂停三选一。4 分钟保证可选三灾双元素，5 分半提供缺失元素，成型不依赖随机稀有掉落。

胡萝卜剑现按用户确认的火元素重制标准统一制作：基础、火、冰、毒、雷、三灾、巨剑、双刃、剑气九组实际生成的透明素材，保留完整原生光晕，不直接抠设定图。双刃使用带连接叶冠的双剑图；巨剑保留银灰包片；三灾与剑气保留完整缠绕。HUD、三选一、暂停、结算和图鉴同步。原始 PNG、提示词和来源清单见 `art/carrot-element-reference/`，实现说明见 [外观重制说明](docs/gdd/blade-weapon-renditions.md)。伤害、攻速、范围与所有成长玩法保持本轮之前版本。

调料商店仍是小调味罐 → 电/火/毒三稀有 → 对应三史诗的七件树。灰、蓝、紫底和连线、价格、原位升级、三件装备位置与出售规则保留。所有怪物必掉金币，需走近拾取。购买第四种有效元素会被槽位限制阻止。

## 存档与交付

每次内容更新直接清除旧档重新开局，不做迁移。存储键 `blade-evolution-save-v1`，结构 v16，另有构建内容指纹；同版本正常保存构筑、待选三选一、战场状态与继续。

本轮只使用 `node scripts/standalone.mjs --blade-only` 生成内嵌全部资源的 `dist/blade-evolution.html`。遵守玩家约定，未运行测试、游戏、浏览器或独立类型检查，不发布 GitHub Pages，不改动或打包荒岛游戏，不提交预先存在的 `.agents/`。

现有试玩网页可能仍是旧版；本轮以源码提交与新版离线 HTML 为准。完整对局平衡和手机实机表现尚未运行验证。
