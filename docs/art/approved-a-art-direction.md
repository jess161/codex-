# A 组果蔬原画接入

玩家已选择 A 组胡萝卜刀与香蕉弓并要求应用到游戏。选稿原图见 [A 组](../images/a-group-approved.png)，原始生成工具为 image_gen.imagegen，接口未显示具体模型版本。

- 造型：A 组的茂密叶柄、橙色分节胡萝卜、黄色香蕉弓、深色果蒂、奶色绳结与绿色握带。
- 画风：圆润轮廓、深蓝描边、手绘明暗和奶油色高光。
- 处理：使用图片编辑工具从 A 图分别提取透明素材，去掉周围光晕，香蕉弓弦单独留给代码绘制。保留生成 PNG 原始像素与元数据，没有重新编码。
- 显示：PNG 作为主体图像，SVG 容器依据透明边界设置画框；这层容器只负责显示与弦的叠加，不重画武器。
- 引擎：沿用 Phaser 3.90 与当前 Canvas/WebGL 路径；图像在 preload 装入，战斗、选择与图鉴使用相同图像键。
- 胡萝卜：原图 2172×724，显示画框 2063×674，画框内握持点 (611,340)，尖端 (2046,340)。根据握持点到尖端距离计算缩放，使图片尖端与近战距离对应。叶柄位于人物后方图层。
- 香蕉弓：原图 1254×1254，显示画框 710×1194，握持点 (578,600)。绳端点为 (117,107) 与 (120,1103)，菜单静态弦与战斗拉弦共用这两个锚点。
- 立体鉴赏：读取素材 alpha 生成轮廓，挤出厚度，原图贴在正反两面。颜色贴图使用 sRGB，正反绘画面使用不受灯光改变颜色的材质，侧面使用深蓝色材质。
- 存档：内容指纹随新图片和代码一起改变，新版首次打开自动清旧档。

素材记录见 [manifest](approved-a-assets.json)。按玩家要求不运行游戏测试、浏览器或试玩，不把本轮描述为已完成运行验收。
