# 独立武器主动技 v0.9

每把武器一个开局即可使用的主动绝招。玩家只需要一个新动作：电脑 `Q`、手机点“绝招”。不耗蓝、不占道具格，不要求瞄准、连招或额外升级菜单。使用后独立冷却 10–14 秒。

原有的自动挥砍、故事被动和瞬步分别保留。新主动技能通过明确的手动输入触发，暂停、升级选择、旧存档保留五件及结算界面均不能释放，不会因为长按、松手、切回游戏而自动重复。

## 简单操作与反馈

- 系统优先朝附近已登场的活敌人释放；秋水优先强敌。没有目标时使用当前朝向，避免增加手动瞄准步骤。
- 三连刺、金月阵、回旋刃、旋风、冰镜、居合、落刀、夺魄、火区、时隙分别有独立可读的表现；继承已有圆润形体、深蓝描边、糖果色和白色高光。
- 绝招按钮置于瞬步旁，显示武器图、就绪/冷却数字与冷却环；选刀和图鉴分别列出主动与被动描述。
- 支持一根手指持续移动，另一根点绝招；放开绝招手指继续移动。按钮大于 44 CSS 像素，检查 390×844、320×568 和 740×360。
- 主动直接命中使用既有打击、音效与短暂停顿反馈。低动态模式保留命中范围和信息，精简旋转和下落；轻量模式降低装饰数量，保留实际伤害和控制。

## 伤害、时间与安全边界

- 主动直接命中参与暴击、终结、元素道具以及击杀奖励，不替代有效近战计数，不递归触发连击型道具。
- 主动击杀仍按敌人原落点产生独立经验球与正常食物概率，不合并、不远程发放、不丢失散落奖励。
- 夺魄治疗受灵护和赤月影响，各应用一次；空挥不回血，单次技能治疗封顶。既有击杀回血可独立工作。
- 时隙不暂停生存/首领时钟，也不拖慢玩家施加的灼烧与毒伤计时；敌方移动、攻击预警、弹丸、震荡波和地面危险区按各自敌方时间推进。
- 身周区域与刀气使用同一实际尺寸绘制。回旋刃有明确去/回阶段，各阶段单目标只命中一次，回程能追随移动中的玩家，并受总行程约束。
- 怪物/弹丸/刀气/危险区沿用原数量上限；主动最多一个持续区域、六个排队命中和两具镜像，主动瞬时表现标准/轻量上限 14/8。

## 存档与验证

沿用 v7，新增可选 `active` 组件，包含冷却、暂时强化、释放次数、待结算攻击及持续区域。旧局缺少该组件时，继续游戏会初始化一个就绪技能；已有道具、生命、经验、实体与随机数不重置。

新的存档保留延迟刺击、飞袭、落刀剩余延迟和目标、区域位置与尺寸、回旋刃去回阶段及命中记录，恢复后不重放第一击或补送额外一次技能。暂停和三选一冻结所有主动计时。

自动检查验证十二种实际机制、不可自动触发、冷却、尺寸、控制抗性、治疗、5000 个散落奖励以及存取一致性。完整对局机器人通过与 `Q`/手机同一输入动作释放主动，仍只使用合法移动、瞬步与真实升级选项，不修改生命、伤害、经验、时钟、冷却或随机数。
