# 按已确认标准重制的胡萝卜剑外观

本轮以用户原图为造型约束，以用户确认的 `fire-glow-refined.png` 为制作标准。用户明确不接受直接抠设定图，因为去底损伤了光晕；本次运行时素材全部来自实际图片生成，原图局部仅作为生成工具输入。

## 本轮交付

九组主要正面外观：基础、火、冰、毒、雷、火冰毒三灾、巨剑、双刃、剑气。补齐基础剑侧面和背面，以及剑气/闪电/三灾的独立完整光效层和巨剑金属包片层。生成原始 PNG、每次提示词、输入原图、登记坐标、无损 WebP 与 SHA-256 保留在美术目录及来源清单。

火沿用已确认稿。冰为蓝白晶体刀身和覆霜叶冠；毒为紫色刀身、荧绿毒液和滴落；雷为金色电纹与完整缠绕电环；三灾保留多色叶冠、三旋纹章和青/紫/绿缠绕。巨剑使用银灰不规则金属包片；双刃是一组带连接叶冠的两把短剑；剑气保留青色流线光环。没有继续使用被否定的旧剑改款或原图抠取版本。

## 接入

`scripts/prepare-carrot-renditions.py` 对生成 PNG 的整张画布登记。所有画布角点均计入公共画框，留出边距后才统一缩放，没有颜色阈值去底、没有按外轮廓锐切光晕。原生透明渐变保留；几何定位使用的透明度阈值只用于物理根尖/立体轮廓计算，不会写回图片透明度。

运行时以约 424 像素宽的无损纹理覆盖常用手机尺寸。`rendition-layout.ts` 由登记脚本生成，共用握点和物理根尖；外部火丝、冰屑、电弧、色环不会扩大攻击范围。原始高分辨率 PNG 始终保留。

原图未逐项画出的形态×元素组合使用生成材质登记。双刃保留其双剑轮廓、连接叶冠和透明间隙；巨剑保留生成的金属包片。完整独立光效层保留跨过实体刀身的环流，避免材质分区截断环形。三灾剑气复用三灾本身的完整青色环流，避免再叠出过密的五道色环。

`carrot-appearance.ts` 只根据现有形态与有效元素选择贴图；没有授予能力或绕过槽位。战斗、HUD、三选一、暂停、结算使用同一套外观；图鉴展示九组主要造型，原有立体鉴赏使用新版基础剑正面/背面。

## 玩法和验证边界

`simulation.ts`、装备伤害/攻速/范围、进化配置、奖励池、经验、金币、商店与存档结构均未改变。仍为 Phaser 3.90 + TypeScript，没有迁移引擎，没有改动荒岛。内容指纹变化后按既有约定直接清旧档，不迁移。

已做源码复核和深/浅背景上的静态美术缩略图检查；只执行割草游戏资源打包，不运行测试、试玩、浏览器或独立类型检查，不将静态图称为游戏截图或实机验收。`.agents/` 不提交，本轮不发布 GitHub Pages。
