# 胡萝卜刀拖地与渐隐刀痕 v2.3

基线为已备份提交 6800dac。使用玩家选定的 A 组胡萝卜图片，加入未挥砍时的贴地姿态与刀痕；同时按玩家补充要求，让刀痕粗细随胡萝卜大小改变。

## 姿态与触点

待机时地面倾角固定为 π/4。按俯视画面的高度投影，计算握持高度和刀身缩短量，使刀尖落在地面；画面上呈右下方 45° 斜放。挥砍预备和收势采用既有缓动，平滑抬起、落下，完整挥砍时恢复原攻击长度。

触点使用 A 组图片的实际握持点、尖端、缩放和旋转计算。挥砍全过程断开地面接触，重新落地后建立新锚点，避免攻击弧线或中断前后的点连成长划痕。刀尖有小范围地面接触阴影，胡萝卜叶柄继续绘制在人物后方。

## 橙色刀痕

- 仅角色实际移动且刀尖接地时产生痕迹，站立只显示接触阴影。
- 颜色为胡萝卜橙色 #f49a43，使用同色淡边和圆形连接点，不产生金属火花。
- 线宽为实际显示高度 ×0.075，限制在 1.6—8 个世界单位；长度增长和宽度成长均通过真实图片尺寸影响线宽。
- 每条刀痕记录创建时的宽度，成长后新痕变粗，已有痕迹保持原粗细继续淡出。
- 沿用拖刀系统约 3 秒的寿命与非线性透明度衰减，记录世界坐标，绘制在角色、怪物和危险预警下方。
- 暂停冻结年龄与生成；恢复、攻击间隔、位置突变和尺寸变化会重建锚点，重开清空痕迹。普通与简化模式继续使用既有数量上限。
