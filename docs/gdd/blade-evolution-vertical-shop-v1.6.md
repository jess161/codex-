# 竖向装备商店

基线 `d6828a9`。按玩家提供的参考图，把商店改为竖向图标目录。装备图标在上、名称在下，价格以小字显示；整页向下滑动浏览。使用原有圆润糖果色装备图，参考图仅用于排列方式。

默认显示全部十四件装备，只保留“全部、防御、攻击、足具”筛选。移除流派下拉框、推荐装备高亮和 HUD 自动流派标签，游戏源码不再带预设搭配目录。装备收益仍独立生效，可以自由组合；用于战斗回归的代表性组合放在测试夹具中。

点击单件图标只选择、展示详情，不扣金币。固定详情区显示属性、当前等级、升级效果、价格、购买或升级，以及已拥有装备的出售按钮。金币不足、六件已满、已有足具和满级显示明确原因。购买后图标角标更新，出售释放位置。保持六件上限、足具限一件、三级上限和 75% 出售返还。

手机使用三列，桌面使用四列，竖向面板居中。320 像素窄屏保留目录滚动及固定购买区。横屏低高度改为左侧目录、右侧详情，使按钮继续可用。背景遮罩隔开暂停战场，底部“继续战斗”和右上关闭按钮都可以返回游戏。

开店仍立即暂停模拟及战斗特效，选装备时间不计入十分钟。图标点选、筛选、买卖不推进战斗；关闭后继续，并清除原有移动和瞬步。键盘焦点留在商店内部，Tab、Shift+Tab、Space 和 Enter 可操作。关闭后焦点回到入口。

金币掉率、武器削弱、怪物、装备数值、保存结构和旧档补偿沿用 v1.5，本轮没有再次修改数值。

验证覆盖四种武器的真实商店流程、图标与名称相对位置、无流派入口、单件选择、购买升级、出售换鞋、六件限制、暂停与恢复、触屏双指、原生纵向和横向滑动、320/390 像素手机、横屏、键盘焦点、刷新及旧档补偿。另检查生产构建和禁网单文件。测试中的金币资助、静止敌人和时间边界为明确的 QA 场景；手机为 Chromium 触控模拟。
