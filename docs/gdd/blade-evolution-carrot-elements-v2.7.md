# 胡萝卜电火毒分区外观 v2.7

基线源码 `770caee81566f8e68db42bd7f5cd060d48a4b10a`。用户明确选择：保留电、火、毒三个商店分支；冰霜本轮只准备外观素材。

## 待机即可辨认

装备麻椒粉／雷鸣椒盐罐后，叶柄出现蓝白电纹、金黄闪电标记和短电弧。装备幽绿菇酱／翠毒蘑菇罐后，橙色刀身的沟纹流动荧绿毒液，下沿有明显毒滴；只有毒时露出紫叶尖。装备辣椒酱／火山辣酱罐后，根尖变为炽红焦纹与发亮裂隙，带小火苗。

多元素同时装备时固定区域：电在叶柄、毒在刀身、火在根尖，图片图层分别叠加。不会整把变成单一元素颜色，后买装备不覆盖其他部位。购买、升级和出售立即依据实际装备决定外观；没有装备时仍使用原 A 组完整胡萝卜原画。

稀有到史诗使用更完整的材质覆盖，同时放大毒滴、火尖和电火花，毒液挥砍飞溅数量增加。HUD 用电纹／毒液／火尖及Ⅰ／Ⅱ标出当前外观等级。小尺寸、45° 横扫、命中距离和完整刀面保持原规则，外部火苗不扩大判定。

## 挥砍、命中与地面

- 火是主挥砍弧：橙红宽弧与暖黄亮边，命中散出少量余烬。
- 毒在挥砍中甩出少量绿滴，普攻命中时产生有边缘轮廓的绿色液滴。
- 电在叶柄有短电弧，原有充能触发的真实连锁闪电继续显示连接线。
- 未附魔时保留原有 1.1 秒橙色刀痕。毒在刀身下沿留下绿色、少量气泡的痕迹，约 1.1 秒淡去；火在真实根尖留下约 0.38 秒熄灭的余烬；电柄留下约 0.35 秒淡蓝短痕。
- 各痕迹在独立通道记录位置、宽度、寿命和颜色，已有痕迹不会因升级重新变色。每通道标准／轻量最多 80／28 段；暂停冻结、重新开局清空。火毒两处可同时留下痕迹。
