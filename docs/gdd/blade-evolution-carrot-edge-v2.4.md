# 胡萝卜刀背视角与攻击范围 v2.4

基线为已备份提交 a74904c。本轮合并玩家连续提出的三项要求：拖动时刀背为主、露出约三分之一刀面；刀痕更快淡化；胡萝卜横扫 45°、香蕉弓射程 140。

## 刀背与刀面

沿用 A 组原画。待机时刀面在横向轴的垂直方向压缩至 1/3，并根据原图 alpha 轮廓采样根身上下边界，补出另外约 2/3 的侧面厚度。刀背使用橙色明暗分面、脊线与深蓝描边，根尖处收拢到原尖端。

抬刀预备时沿原缓动展开；有效横扫时为完整刀面，刀背厚度收为零；收势时反向合回。现有贴地倾角与刀尖位置继续使用，橙色刀痕宽度按完整刀身尺寸计算，不因只露出 1/3 刀面而缩小。

## 更快淡去与固定范围

- 胡萝卜刀痕寿命改为 1.1 秒，保留非线性渐隐、移动才新增、暂停冻结和重开清空。
- 胡萝卜横扫的总扇形角度为 45°，即瞄准方向两侧各 22.5°；属性计算不再随掌握阶段增加此角度，挥砍拖尾同步显示该扇形。
- 香蕉弓实际射程固定为 140，不再套用此前 0.9 倍初始缩减或掌握阶段射程增长。当前模式下自动选敌和瓜子箭最大行程读取同一实际射程。
- 首页、选择页、图鉴、基础攻击说明及数值栏同步采用当前参数。
