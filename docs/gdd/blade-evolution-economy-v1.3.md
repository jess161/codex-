# 十分钟金币与通用装备版

源码基线：`2865433` 的四种普通武器版本。本轮取消三十件旧道具及六组套装，使用独立的金币与装备系统。普通刀横扫、剑快斩、弓自动单箭、矛直线贯穿继续保留，不加入技能树。

## 一局节奏

总时限 600 秒：前 540 秒怪潮，最后最多 60 秒首领战；可提前击败首领结束。首领登场不暂停、不清除移动手势。正常升级、金币拾取和装备购买都保持连续战斗。只有玩家主动暂停、打开设置等菜单或切到后台才暂停。

商店是战场上的紧凑浮层，不覆盖整个战场，不随机刷新、不强制三选一。按 B 或点金币旁的“商店”开关。按一次 Esc 先关闭商店，再按才暂停。三类装备各有三个固定选择，全部通用于四种武器，拥有即生效，不占武器格，不存在套装条件。

## 装备

每件最高 5 级，首次购买和后续升级均花金币。第 n 级购入价 = 基础价 + (n−1)×24。同一装备升级只更新底部原图标，不追加副本。

| 类别 | 装备 | 基础价 | 每级效果 |
| --- | --- | --- | --- |
| 防御 | 果冻护心 | 30 | 最大生命 +20，购入时恢复 20 |
| 防御 | 泡泡护甲 | 35 | 所有受到的伤害 −6%，五级 −30% |
| 防御 | 蜜露护符 | 28 | 每 5 秒恢复 2 生命，五级恢复 10 |
| 攻击 | 星糖晶核 | 32 | 基础攻击伤害 +18% |
| 攻击 | 发条握柄 | 36 | 当前攻击间隔、准备、出手、收势均 ×0.92 |
| 攻击 | 聚能透镜 | 30 | 攻击距离 +12% |
| 足具 | 疾风短靴 | 28 | 移动速度 +7%，同步改善加速 |
| 足具 | 弹簧步靴 | 32 | 瞬步冷却 −0.4 秒，五级 3 秒；当前剩余冷却同步减少 |
| 足具 | 拾光长靴 | 26 | 金币和经验吸取范围 +18% |

所有防御和足具直接作用于持有者；攻击加成统一作用于刀、剑、箭和矛。刀剑距离增长保持扇形，剑扫角仍受窄幅上限约束；长矛延长恒宽直刺；弓延长箭矢寿命与索敌距离，仍然单箭单命中。发条会加快弓的拉弦和其他武器动作，不只是修改表面显示的“攻速”。购买时已开始的动作保留原时长，下一次使用新数值。

生命、攻击距离成长不增加本版的移动负担。没有旧元素飞刃、雷电、火种和套装叠加，金币也不参与战斗 RNG。

## 金币

| 怪物 | 单次击杀掉落金币 |
| --- | --- |
| 软团 / 裂壳幼团 | 1 |
| 疾爪 | 2 |
| 吐弹者 / 裂壳母团 | 3 |
| 甲壳 / 赤角冲兽 / 游灯幽魂 / 毒气泡团 / 爆燃球 | 4 |
| 针背刺团 / 隐纹幽球 | 5 |
| 裂甲先锋 | 25 |
| 圆甲暴君 | 100 |

金币在击杀位置形成独立掉落，图标大小体现价值；不会远程记账。走到 48 单位的初始吸取范围内才靠近，进入 18 单位领取，落地延迟 .22 秒；拾光长靴扩大吸取范围。敌人自己引爆不计玩家击杀，也不生成击杀金币。首领的金币仍是终局地面掉落，不会自动进钱包。

金币、经验和食物相互独立。远处金币保留坐标，不设数量上限、不因轻量模式或首领转换丢弃。只有视野内创建精灵。每次掉落和拾取各结算一次，钱包与累计获得 / 花费满足守恒。金币仅属于本局，结算后新局重置。

## 操作与底栏

底部没有空槽、未拥有装备、品质筛选或套装提示，只显示已买装备图标和小等级标记；数量超出宽度时左右滑动。点图标在对应商店分类查看与升级，不暂停。金币数量和商店入口位于上方，不占装备底栏。

手机可一根手指保持摇杆，另一根购买或切换分类。金币实时入账只更新价格可用状态和余额，不替换正在按下的按钮；防止手指抬起时购买被吞掉。底栏滑动不会驱动角色走位。320×568 竖屏和 740×360 横屏保留可操作的商店、瞬步与底栏。

## 美术

新金币与九件装备以 128×128 内嵌 SVG 绘制：圆润糖果配色、深蓝描边、渐变与白色高光。角色、怪物、四种武器和战场沿用已有造型。旧三十件道具图片不再加载到新版运行资源中。

## 存档迁移

新局使用 v9。读取 v1—v8 先按历史规则验证，再转换普通武器和金币系统。已持有旧道具每级折算 36 金币，旧锻造每层折算 18 金币（修复消耗不折算）；未拾取旧道具变成原地 20 金币，同一组候选只转换一次。旧装备、旧套装、专属状态与在飞技能清除。

保留等级、经验、世界位置、经验球、食物、怪物、随机流和永久战绩。旧进度按比例映射至九分钟怪潮与一分钟首领；生命按原有生命比例映射到去除旧装备后的上限，避免残留旧护心加成。转换只执行一次，后续 v9 原样恢复余额、装备、回血计时、在飞箭和所有地面金币。

v9 验证金币非负整数、收支守恒、实际购买价格总和、装备等级 / 顺序、恢复计时和金币面额；拒绝混入旧装备与套装数据。

## 验证

- `npm test`：包含九件装备在四种武器上的 36 组实际行为断言、十四种怪物金币、走近拾取、收支、购买拒绝、5000 颗金币、存档、迁移与十分钟边界。
- 四种普通武器分别通过完整正常输入对局，实际杀怪、捡金币与购买升级，不修改生命、伤害、时钟、经验或随机数。自动通关证明可达性，不代表真人难度结论。
- `npm run test:economy`：桌面和手机浏览器的真实菜单、金币拾取、购买、双指、钱包更新期间抬指购买、底栏滑动、精确刷新、旧存档迁移和首领连续进入。
- `npm run build`、`npm run test:offline`：类型检查、构建与禁网运行。当前浏览器禁用 `file://`，离线检查使用构建后的实际 HTML 字节在内存中提供页面，禁用全部网络。

历史十五种武器、三十件道具、套装和旧掉落浏览器脚本仅用于了解历史版本，不作为当前 UI 验收。历史模拟规则仍用于验证旧数据的读取能力。
