# 《刃之进化》游戏设计文档（GDD）

**版本：v0.1｜日期：2026-10-27｜状态：立项与原型设计稿**

> 从一把不起眼的小刀开始，砍出一局属于自己的神兵。

**已确认的方向：单局进化，每局重新从小刀成长，节奏接近割草肉鸽。**

本稿默认采用 **2D 俯视、单人 PvE、手机竖屏优先、电脑自适应**。背景参考《球球大作战》的干净场地、清晰圆形单位与轻量视觉；角色、刀型、界面和音效使用原创设计。本稿描述一款独立新游戏。

文中的数值、节奏和性能指标均为**原型起始参数与待验证目标**，尚未经过可玩原型验证。

---

## 1. 游戏定位

| 项目 | 设计 |
| --- | --- |
| 暂定名称 | 刃之进化 |
| 核心类型 | 轻操作割草肉鸽、武器进化、生存挑战 |
| 玩家幻想 | 亲眼看着手里的小刀，成长为能一刀清出道路的神兵 |
| 核心动作 | 走位、自动挥砍、收集经验、选择锻造、瞬步避险 |
| 单局结构 | 7 分钟生存阶段，接最多 90 秒首领战；最长 8 分 30 秒 |
| 胜利条件 | 在首领阶段时限内击败首领 |
| 失败条件 | 生命降至 0，或首领战倒计时结束 |
| 局内成长 | 主刀 Lv.1—30，6 个形态，5 次锻造选择 |
| 局外保留 | 刀型图鉴、已解锁的角色配色、成就、最佳战绩 |
| 下一局 | 主刀回到 Lv.1，生命和瞬步状态重置；数值强化重新选择 |

### 体验支柱

1. **升级看得见。** 刀身轮廓、刀刃长度、挥砍轨迹和音色都随成长改变。
2. **走位创造爽感。** 把怪群引到刀锋前，一次斩中多个目标，比追着单只怪跑更有效。
3. **战场保持清楚。** 背景简洁，华丽集中在刀和命中的短暂时刻，危险预警始终醒目。
4. **每局有不同解法。** 同一把主刀通过锻造选择形成伤害、攻速、范围或控场倾向。

## 2. 核心循环

```text
开局小刀 → 走位聚怪 → 自动挥砍 → 怪物掉落经验 → 靠近吸收
                ↑                              ↓
                └──── 刀升级、攻击变强 ←─────────┘
                              ↓
                   关键等级：进化＋锻造三选一
                              ↓
                  更高密度与更复杂的怪物组合
                              ↓
                     击败首领／生存失败
                              ↓
                记录战绩、解锁图鉴 → 再开一局
```

**局内动力：** “再升一级就能换刀型”与“再聚一波怪就能清得更爽”。

**局外动力：** 补全六阶刀型、尝试不同锻造组合、刷新最佳成绩与挑战成就。

### 首次游玩的目标节奏

| 时间 | 希望玩家发生的体验 |
| --- | --- |
| 0—5 秒 | 明白如何移动，看见角色身边的刀 |
| 5—15 秒 | 完成击杀、吸收经验并升到 Lv.2 |
| 45—75 秒 | 第一次明显换刀型，理解“这局会越打越华丽” |
| 约 3 分钟 | 已体验数次进化，开始理解聚怪与锻造取舍 |
| 5 分 20 秒—6 分钟 | 获得第六形态，留出至少约 1 分钟体验，再进入首领战 |
| 7 分钟 | 首领登场，检验本局成长和走位能力 |

时间为目标区间。升级只来自战斗与拾取经验，不按计时器直接发放等级。

## 3. 操作与相机

### 3.1 操作方案

首版采用**自动普攻＋手动移动＋一个瞬步按钮**。

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD／方向键 | 左侧浮动摇杆 |
| 普攻 | 自动向附近目标挥砍 | 同左 |
| 瞬步 | 空格／点击战场 | 右下瞬步按钮 |
| 锻造选择 | 点击／数字 1、2、3 | 点击选项 |
| 暂停 | Esc | 右上暂停按钮 |

点击界面按钮、选择卡片时，不触发战场瞬步。

普攻不需要手动瞄准。目标只在两次攻击之间切换：优先选择进入攻击范围的最近敌人；已有目标仍有效时，仅当另一目标明显更近才切换，避免刀的朝向来回抖动。没有目标时，刀停留在角色身侧，不持续空挥。

### 3.2 相机与场地

- 固定 2D 俯视相机，平滑跟随角色。
- 使用无边界、无阻挡的平面场地，背景纹理随相机平移。
- 手机竖屏和电脑横屏以**短边 540 个逻辑单位**为参考，保持角色和刀的相对尺寸。
- 刀升级时保持相机缩放稳定，保留武器实际变大的视觉回报。
- 首版不设置会遮挡怪物或刀光的大型场景装饰。

## 4. 战斗规则

### 4.1 玩家基础参数

| 参数 | 起始值 |
| --- | ---: |
| 生命 | 100 |
| 角色碰撞半径 | 16 |
| 移动速度 | 210 单位／秒 |
| 初始近战伤害 | 14 |
| 初始攻击间隔 | 0.80 秒 |
| 初始有效攻击半径 | 64 |
| 初始攻击扇形 | 100° |
| 受伤后的全局无敌时间 | 0.65 秒 |
| 对普通怪的基础击退距离 | 18 单位 |

移动不消耗体力，挥刀不强制停下移动。生命是主要生存资源，瞬步通过冷却限制使用。

### 4.2 一次挥砍如何结算

一次普攻由起手、有效挥砍、收刀组成，基础总表现时长约 0.22 秒，有效伤害窗口约 0.08—0.16 秒。

- 有效区域是角色面前的扇形，可同时命中多个敌人。
- 同一敌人在同一次挥砍中只受一次伤害。
- 刀气是独立攻击实例，可与近战各命中同一敌人一次。
- 检测使用扇形与敌人碰撞圆的相交；挥砍跨帧时需要覆盖完整扫过区域。
- 发光、残影、碎屑不额外产生伤害。
- 刀光的有效外沿要与命中范围一致，外层柔光允许小幅超出。

普通怪受击产生短促压缩、轻微击退和碎屑。精英有击退抗性；首领不受普通击退，避免持续攻击将首领锁死。

### 4.3 瞬步

- 位移 140 单位，持续 0.18 秒，冷却 5 秒。
- 起始 0.12 秒无敌，可穿过怪物身体。
- 方向采用最近一次有效移动方向；开局默认朝上，不跟随自动攻击目标改变。
- 冷却在按钮外围显示环形进度，结束时给一次轻提示。
- 瞬步不额外造成伤害，其价值是脱围、躲预警和调整聚怪位置。

## 5. 经验、升级与局内节奏

### 5.1 经验规则

怪物死亡后掉落经验点。普通经验点吸附半径为 84 单位，进入吸附范围后飞向玩家，接近角色时到账。

- 升级对象统一为“刀”，HUD 只有一条刀经验条。
- 一次获得大量经验可连续升级，溢出经验完整保留。
- 普通升级自动完成，不弹出选择窗口。
- 到 Lv.5／10／15／20／25 时，触发刀型进化与一次锻造三选一。
- Lv.30 满级；之后经验仍计入战绩分数，经验条显示“满级”。
- 所有关键形态均可通过正常升级获得，不依赖随机掉落稀有素材。

### 5.2 初始经验曲线

从等级 L 升到 L+1 所需经验：

`XP_next(L) = 10 + 3 × L + 5 × floor(L / 5)`，适用于 L=1…29。

| 目标等级 | 从 Lv.1 起累计经验 | 目标到达时间 |
| --- | ---: | --- |
| Lv.2 | 13 | 5—15 秒 |
| Lv.5 | 70 | 45—75 秒 |
| Lv.10 | 250 | 1 分 20 秒—1 分 50 秒 |
| Lv.15 | 530 | 2 分 30 秒—3 分钟 |
| Lv.20 | 910 | 4 分钟—4 分 40 秒 |
| Lv.25 | 1,390 | 5 分 20 秒—6 分钟 |
| Lv.30 | 1,970 | 6 分 30 秒—7 分钟，熟练玩家目标 |

后期通过更高的怪物密度、混合敌人和精英经验提高获取速度。调参时分别验证经验获取速度、升级需求和敌方压迫程度。

### 5.3 恢复与升级演出

- 普通升级不自动恢复生命。
- 每次刀型进化恢复 8 点生命，恢复不超过当前生命上限；进化本身不提高生命上限。
- 形态进化先暂停战斗与关卡时钟，展示旧刀到新刀约 0.45 秒的变化，再给锻造选择。
- 选择结束后恢复战斗，玩家有 0.35 秒保护时间；解除选择时残留的按键或触摸输入。
- 同一次经验结算跨过多个进化点时，每个进化点只结算一次锻造机会，按顺序处理。

## 6. 六阶刀型与外观进化

### 6.1 刀型表

| 形态／等级 | 刀名 | 轮廓变化 | 颜色与特效 | 攻击半径／扇形 | 基础攻击间隔 |
| --- | --- | --- | --- | --- | --- |
| I · Lv.1—4 | 铁片小刀 | 短直刃、简短刀柄、轻微缺口 | 灰银，短而清楚的白色挥砍线 | 64／100° | 0.80 秒 |
| II · Lv.5—9 | 青锋 | 刃身拉长，出现完整护手 | 银白配青绿刃线，短残影与命中火花 | 74／110° | 0.72 秒 |
| III · Lv.10—14 | 燎火刃 | 弯曲刀尖、背部火纹 | 暖橙刀锋、弧形火尾、少量余烬 | 84／120° | 0.65 秒 |
| IV · Lv.15—19 | 雷鸣斩 | 分叉护手、刀背锯齿电纹 | 蓝紫亮边、细电弧、锋利折线尾迹 | 94／135° | 0.58 秒 |
| V · Lv.20—24 | 星陨长刀 | 长刀配宽刃，嵌入星核 | 靛蓝配金边、稀疏星尘、分层扇形刀光 | 106／150° | 0.52 秒 |
| VI · Lv.25—30 | 破晓神刃 | 镂空刃脊、白金护手、悬浮饰片 | 白金刀刃、半透明残影、沿有效扇形展开的金色光环 | 118／170° | 0.47 秒 |

**每次形态变化至少改变两项轮廓特征。** 缩小显示或去掉颜色后，也应能分辨当前阶段。

### 6.2 普通等级也有视觉反馈

同一形态内部，随等级小幅增加刀刃明亮程度、刀纹完整度与尾迹清晰度。所有变化都在该形态的视觉预算内。

Lv.30 完成最后一段刀纹与饰片点亮，标记为“极境”；仍属于第六形态，避免再引入一套新武器规则。

### 6.3 伤害成长

`单次近战伤害 = 四舍五入[(14 + 2 × (L−1)) × 形态系数 × 锻造伤害倍率]`

六阶形态系数依次为：`1.00 / 1.10 / 1.25 / 1.40 / 1.60 / 1.85`。

无锻造时，关键等级伤害依次约为：Lv.1：**14**、Lv.5：**24**、Lv.10：**40**、Lv.15：**59**、Lv.20：**83**、Lv.25：**115**、Lv.30：**133**。

这使得早期需要两刀击杀的普通怪，第一次形态升级后即可一刀击杀。敌人的血量按波次配置，不跟随玩家等级同步上涨。

### 6.4 刀气成长

| 解锁点 | 刀气规则 |
| --- | --- |
| Lv.10 | 每第 4 次普攻释放一次刀气；伤害为当前近战伤害的 60%，距离 180，命中 1 个目标 |
| Lv.15 | 每第 3 次普攻释放；距离 220，可穿透 3 个目标 |
| Lv.20 | 每第 3 次普攻释放；距离 260，可穿透 5 个目标 |
| Lv.25 | 每第 2 次普攻释放；距离 300，可穿透 8 个目标 |

刀气沿本次挥砍的主要方向发射。后续形态替换对应的元素表现，避免火焰、电流、星尘无限叠加。雷线只连接本次刀气实际命中的敌人。

## 7. 锻造三选一

每次进化给 3 个不同选项，整局共选择 5 次。卡片用“一句作用＋明确数值＋当前层数”表达。

| 锻造 | 每层效果 | 层数上限 | 玩家取舍 |
| --- | --- | ---: | --- |
| 锋利 | 伤害 +15% | 3 | 更快击杀精英与首领 |
| 轻刃 | 攻击间隔 −8% | 3 | 更密集的攻击，提升刀气释放频率 |
| 广域 | 近战攻击半径 +8% | 2 | 更容易一刀命中多个敌人 |
| 牵引 | 经验吸附半径 +35% | 2 | 减少拾取时的危险走位 |
| 震刃 | 普通怪击退距离 +35% | 2 | 为怪群密集阶段争取空间 |
| 坚韧 | 生命上限与当前生命各增加 15 | 2 | 提高容错，适合需要稳住局面的玩家 |

同类百分比加成按层数相加。攻击间隔经过全部加成后最低为 0.32 秒；近战攻击半径经过加成后最高为 140。

生成选项时排除已满层内容。若可用项目不足 3 个，使用“恢复 20 生命”补位，该补位不提高生命上限。

预期出现三类常见玩法：

- **斩群：** 广域＋轻刃，通过走位和大范围快速清怪。
- **破甲：** 锋利＋轻刃，集中提升精英与首领输出。
- **稳进：** 牵引＋震刃＋坚韧，降低拾取和脱围风险。

这三类共享同一条六阶刀型路线，不要求三套独立武器资产。

## 8. 怪物与首领

### 8.1 普通怪物

| 类型 | 简单识别形状 | 基础生命 | 接触伤害 | 移速 | 经验 | 行为与作用 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| 软团 | 绿色圆体、两只眼 | 22 | 10 | 80 | 3 | 直接靠近，提供主要清怪爽感 |
| 疾爪 | 红橙小水滴、尖尾 | 16 | 8 | 155 | 4 | 从侧面接近，打破单方向后退 |
| 甲壳 | 深蓝六边体、厚外框 | 90 | 14 | 65 | 7 | 混在怪群中，检验伤害与路线选择 |
| 吐弹者 | 紫色圆体、单眼与炮口 | 28 | 8 | 75 | 6 | 保持距离，发射可预判的慢速子弹 |

基础生命按时间修正：软团、疾爪、吐弹者乘以 `1 + 0.08 × 已经过的整分钟数`；甲壳乘以 `1 + 0.12 × 已经过的整分钟数`。移速不随玩家升级自动增加。

吐弹者最多同时存在 6 只；发射前预警 0.5 秒，射击间隔 2.8 秒，子弹速度 150，伤害 12。子弹瞄准发射前记录的位置。

### 8.2 精英

在 **1:30／3:00／4:30／6:00** 各出现一只精英，生命起始值分别为 **450／1,000／1,800／2,800**。

- 使用普通怪的放大轮廓与明显描边，补充一项有预警的冲锋或扇形攻击。
- 击杀给 25 经验，并掉落一个恢复 10 生命的补给球。
- 精英击杀目标耗时约 8—18 秒，随锻造和走位变化。
- 精英不因玩家没有捡到经验而自动变弱，也不随玩家伤害提升补血。

### 8.3 首领：圆甲暴君

7:00 出场，基础生命 **10,000**，碰撞半径 42，正面视觉体积显著大于普通怪。

首领接触伤害为 20，冲撞伤害 25，震荡波伤害 20；所有伤害源共用玩家的受伤无敌窗口。

| 招式 | 预警与表现 | 玩家应对 |
| --- | --- | --- |
| 直线冲撞 | 预警 0.8 秒；速度 360，持续 0.6 秒；收招 1.1 秒 | 横向移动或瞬步躲开，利用收招贴近输出 |
| 环形震荡 | 预警 0.9 秒；波纹厚度 18、速度 220、最远 240，保留固定的 70° 缺口 | 寻找缺口，或正确计时瞬步穿过波纹 |
| 召唤疾爪 | 每次 2 只，间隔至少 12 秒；距玩家至少 180，出生提示 0.8 秒 | 清理侧面压力，利用扇形和穿透刀气兼顾首领 |

冲撞与震荡轮流使用，招式之间保留约 1 秒空档，召唤穿插其中；同一时刻只执行一项主动招式。生命低于 50% 后，空档缩短约 20%，预警时长保持不变，收招最短 0.8 秒。首领开始攻击前需处于玩家可见范围，避免突然从画面外造成伤害。

召唤怪上限为 6，只掉正常经验，不额外掉补血球。首领本身不受普通击退。

不按玩家的锻造结果动态增加首领生命，保留构筑提升带来的实际回报。

起始数值校验：Lv.25 无锻造时，近战理论 DPS 约 245，加上刀气约 318。若有效攻击时间占 60%，击败 10,000 生命约需 52 秒；实际结果需通过原型验证。

## 9. 关卡时间线与难度

| 阶段 | 怪物组合／压力 | 成长体验 |
| --- | --- | --- |
| 0:00—0:45 | 以软团为主，场上数量少 | 学会走位、自动攻击与拾取 |
| 0:45—1:30 | 加入疾爪，逐渐出现包夹 | 第一轮换刀，理解瞬步 |
| 1:30—3:00 | 第一只精英，少量甲壳和吐弹者加入 | 刀气解锁，开始形成锻造倾向 |
| 3:00—4:30 | 混合怪群，第二只精英 | 需要为拾取经验规划回切路线 |
| 4:30—6:00 | 密集怪群与精英交替，射手受数量限制 | 大范围清怪与频繁进化的高峰 |
| 6:00—7:00 | 压力达到最高，保留可识别的脱围方向 | 用最终刀型体验完整威力 |
| 7:00—8:30 | 最长 90 秒首领战 | 检验输出、避险和时机选择 |

### 刷怪约束

- 常规怪优先在可视区域外出生，保留足够靠近时间。
- 开局教学例外：首批 3 只软团可在可视区域内、距离玩家约 170—220 的安全位置出现，先给出生提示。
- 不在玩家身上或瞬步落点即时生成可伤害敌人。
- 刷怪强度由时间和场上压力共同控制；数量满额时暂缓生成，积压生成额度最多保留 3 秒。
- 初始刷怪尝试强度从约 1.4 只／秒逐步增加至约 3.8 只／秒，实际生成受上限约束。
- 远离玩家的敌人离场后按正常规则补充，不带着已开始的攻击直接移动回玩家身边。

### 首领阶段切换

进入首领战时暂停 1 秒，清理敌方子弹，剩余普通怪退场；未击杀的怪不补发击杀经验。已掉落的经验自动吸入，恢复 15 点生命，再开始 90 秒首领倒计时。

期间如触发进化选择，倒计时一同暂停。倒计时到 15 秒时给明显提示，归零时本局挑战失败。

## 10. 简洁画面与华丽刀光

### 10.1 背景与单位

- 背景采用米白／浅灰蓝底色，如 `#F4F7FA`。
- 以极淡网格或稀疏灰点提供移动参照，建议间距约 56 个逻辑单位。
- 彩色、发亮的小点用于经验，背景装饰保持低饱和，避免误认。
- 主角采用圆形身体、简单表情、明确外框；敌人用轮廓、纹样和颜色共同区分。
- 不依赖复杂地形、写实贴图或大量装饰建立画面品质，重点打磨比例、描边、阴影、动效和反馈。

### 10.2 特效升级的四个维度

1. **形：** 短刃变长刀，护手、刀尖、刃背和镂空结构逐步改变。
2. **光：** 白色短线变成有内外层次的彩色刀弧，最终形成清晰的白金斩击。
3. **动：** 短残影逐步增加分层尾迹、局部电弧和饰片跟随。
4. **反馈：** 命中压缩、受击火花、刀声与重击停顿共同增强重量。

### 10.3 清晰度硬规则

- 后续形态替换前一形态的主要特效；同时存在的效果数量有上限。
- 首领与敌方预警、危险子弹必须显示在装饰刀光之上。
- 单次刀光强表现约 0.12—0.25 秒，不持续铺满整个屏幕。
- 常态武器特效尽量覆盖屏幕 15% 以内；瞬间高峰尽量不超过约 25%。这是视觉检查目标，不是伤害判定标准。
- 最终刀环沿实际攻击扇形展开，不能画成会让玩家误以为有 360° 伤害的完整圆环。
- 震屏和闪光可关闭，并遵循系统减少动态效果偏好。

建议层级：**背景 → 经验与软阴影 → 实体与刀身 → 刀光 → 敌方预警与子弹 → 少量数字 → HUD**。

### 10.4 命中与声音

普通怪以局部压缩和碎屑反馈为主。精英、首领或关键重击可触发约 20—35 毫秒停顿，最多每 0.2 秒触发一次。

刀声从短促金属声，逐步增加风声、火鸣、电弧与星鸣层次；升级不通过不断增加总音量制造刺激。密集命中合并播放，危险预警音优先。

## 11. 界面与新手引导

### 11.1 开始界面

中间展示本局起始小刀，旁边显示下一形态剪影；主按钮为“开始试炼”。图鉴与最佳战绩作为次级入口。

已解锁的角色配色不改变刀身进化顺序。图鉴可预览获得过的形态，战斗中的刀型始终对应本局等级。

### 11.2 战斗界面

| 位置 | 内容 |
| --- | --- |
| 顶部 | 刀等级与经验条；靠近关键等级时显示“下一级形态：Lv.XX” |
| 左上 | 简洁生命条 |
| 右上 | 计时、暂停；首领阶段显示倒计时 |
| 场地中心 | 角色、刀、怪物和危险预警，保持主要空间开放 |
| 手机底部 | 左摇杆、右瞬步按钮与冷却环 |
| 短暂反馈 | 升级、进化、一刀多杀；避免每只怪弹出大量文字 |

锻造界面暂停游戏，三张卡片展示作用、数值和层数。支持触控与键盘选择。

### 11.3 新手引导

1. 开局只提示移动与“靠近怪物，刀会自动挥砍”。
2. 首次掉落经验时短暂提示“靠近光点，刀会升级”。
3. 首次进化强化展示刀型变化，不增加额外教程弹窗。
4. 首次明显包夹或精英预警时提示瞬步。

## 12. 结算、重开与局外内容

结算页优先展示本局最终刀型，其次为存活时间、最终等级、击杀数、最高单刀击杀数、锻造组合与失败原因。

战绩分的初始计算为：`本局经验总获取量 + 10 × 普通怪击杀数 + 150 × 精英击杀数 + 1,000 × 是否获胜 + 胜利时首领战剩余整秒数 × 10`。经验总获取量包含已用于升级的经验及满级后的经验。最高单刀击杀按同一次近战挥砍统计，不合并独立刀气的击杀。

### 局内与局外边界

| 内容 | 本局结束后 |
| --- | --- |
| 刀等级、经验、锻造、生命、瞬步冷却 | 下一局重置 |
| 曾经到达的刀型、成就、角色配色 | 永久保留 |
| 最佳战绩、历史结算 | 保留 |
| 中途退出的有效对局快照 | 同一浏览器可选择继续；继续后仍是同一局 |
| 已死亡或已经通关的对局 | 不提供结算后回档继续 |

永久内容以收藏和展示为主。首版不设置局外攻击力、生命或攻速加点，保证每局小刀重新成长的体验。

### 首版成就建议

- **第一柄神兵：** 首次达到 Lv.25。
- **一刀开路：** 单次近战击杀至少 8 只敌人。
- **连斩时刻：** 10 秒内击杀至少 15 只敌人。
- **刀锋舞者：** 首领战无伤通关。
- **百炼成锋：** 完成 5 次标准局。

成就可解锁角色配色或图鉴印记，不提供战斗数值优势。

## 13. 首版范围

### MVP 必须完整交付

- 1 个干净的无边界场地主题。
- 1 名可移动角色，自动挥砍、瞬步与完整受伤／死亡反馈。
- 1 条 Lv.1—30 成长线，完整 6 阶刀型及对应特效与音效。
- 6 种锻造选项，5 次关键等级三选一。
- 4 种普通怪、精英变体、1 个具有 3 招的首领。
- 一套 7 分钟生存＋90 秒首领阶段的刷怪配置。
- 开始、暂停、锻造、图鉴、结算、快速重开与本地存档。
- 电脑和手机操作，特效简化与动态效果设置。

### 后续扩展

无尽模式、额外刀型路线、更多场地主题、更多首领、在线排行、联机与赛季内容可在首版验证后评估。

### 制作顺序

| 里程碑 | 产出 | 进入下一步的条件 |
| --- | --- | --- |
| M1：砍怪手感 | 移动、挥砍、软团、经验与前两阶刀型 | 聚怪和多目标挥砍有明确乐趣 |
| M2：完整进化 | 30 级、6 阶刀型、刀气与锻造 | 每阶外观、手感和收益可辨认 |
| M3：完整一局 | 混合怪群、精英、首领、胜负与重开 | 能走完一局，失败原因清楚 |
| M4：设备与画面 | 手机触控、性能分级、图鉴和存档 | 特效密集时仍能看到危险并可靠操作 |

M1 是内部验证切片；对外首版的验收范围仍包含完整六阶进化。

## 14. 技术建议与性能预算

### 14.1 架构

建议采用 **Phaser＋TypeScript＋Vite 的独立 2D 入口**，保持本游戏的输入、数据和存档与其他游戏分开。

- 模拟层：伤害、升级、掉落、锻造、怪物 AI、计时和胜负。
- 渲染层：角色与刀、动画、特效、镜头和对象复用。
- DOM 界面层：菜单、锻造、图鉴、结算和设置。
- 配置层：刀型、怪物、经验曲线、波次、首领与特效预设。

刀身外观动画不作为伤害判定来源。每次挥砍和刀气有独立 ID 与已命中集合，避免因帧率、动画或残影重复造成伤害。

### 14.2 性能起始预算

| 项目 | 标准档 | 简化档 |
| --- | ---: | ---: |
| 同屏敌人硬上限，含精英 | 120 | 80 |
| 同屏敌方子弹上限 | 32 | 24 |
| 经验对象上限 | 150 | 100 |
| 装饰粒子上限 | 280 | 100 |
| 刀光层数 | 最多 3 层 | 1 层＋清楚的刀身 |
| 画面目标 | 电脑参考设备稳定 60 FPS | 手机参考设备稳定 30 FPS，争取 60 FPS |

设备基线须在原型阶段记录浏览器、机型和分辨率后确定。上述 FPS 是验收目标，尚无实测结果。

简化档首先减少残影、粒子与发光层；敌人的预警时间、攻击频率和碰撞规则保持一致。不同敌人数量上限下，经验获取速度与通关难度需要分别测试。

敌人、刀气、数字、经验点使用对象池。经验对象超出预算时合并邻近经验点，保留经验总量。碰撞候选使用空间网格筛选。

### 14.3 存档

建议存档键名为 `blade-evolution-save-v1`。

- 永久数据：图鉴、成就、配色、最佳成绩、设置与版本号。
- 对局快照：本局等级与经验、锻造、生命、位置、波次、敌人／子弹／掉落、首领状态及随机种子状态。
- 自动快照最多每 5 秒一次；进化选择后、暂停、切后台与结算时额外保存。
- 普通切后台暂停模拟，不在后台继续受伤或获得离线经验。
- 继续对局时恢复同一组状态，不重抽锻造、不刷新精英奖励。
- 版本不兼容时保留可迁移的永久数据；对局无法恢复则明确提示。

## 15. 验收与调参

### 功能验收

1. 普攻范围内多名敌人能受伤，同一次挥砍对同一目标只结算一次。
2. 经验溢出可连续升级，五次进化与锻造机会均不会丢失或重复。
3. 完整六阶刀型在实际战斗中出现，刀气规则与视觉一致。
4. 瞬步方向可预测，无敌窗口与冷却生效，界面点击不误触瞬步。
5. 暂停、锻造与切后台停止模拟；恢复后没有延迟的瞬间伤害。
6. 一局可正常胜利、死亡或因首领时限结束而失败，并正确结算和重开。
7. 新局数值重置，永久图鉴与战绩保留；中途继续不会重新抽取锻造。
8. 在标准档和简化档分别完成高密度场景的输入、判定与存档测试。

### 体验验收目标

| 检查 | 目标／观察方法 |
| --- | --- |
| 首次理解 | 约 80% 的首次测试者能在 15 秒内完成击杀与拾取 |
| 第一次进化 | 典型首次玩家在约 75 秒内到达 Lv.5 |
| 完整成长 | 熟悉操作的玩家在约 6 分钟前获得第六形态 |
| 刀型辨识 | 隐去等级数字、缩小显示后，测试者仍能区分 6 阶中的至少 5 阶 |
| 后期清晰度 | 高密度怪群、刀气和最高刀型同时出现时，预警和子弹仍可辨认 |
| 走位价值 | 原地持续站立会在后续阶段遇到明确风险，瞬步和聚怪能改善表现 |
| 构筑价值 | 不同锻造组合能改变清群、拾取和首领输出的表现 |
| 失败归因 | 测试者能指出死于包夹、预警、拾取路线或首领时限等具体原因 |

建议先以 5—10 名首次玩家验证操作理解，再用多种固定锻造组合与刷怪种子验证数值。目标比例用于调参，不代表当前已有的测试结果。

### 关键风险与处理方向

| 风险 | 处理方向 |
| --- | --- |
| 升级看不出来 | 加强刀型轮廓差异、挥砍轨迹与命中声音 |
| 最终形态出现太晚 | 提升后段经验获取或调整后段经验需求，留足体验时间 |
| 华丽特效遮住危险 | 限制常态层数，缩短强光持续时间，抬高预警绘制层级 |
| 自动攻击缺乏操作乐趣 | 强化聚怪、多目标挥砍、拾取路线与瞬步时机的价值 |
| 某种锻造组合独占优势 | 比较清怪、拾取、生存与首领输出，分别调整收益 |
| 简化档明显更难或升级更慢 | 联合调整刷怪节奏和掉落配置，维持相近的目标进化时间 |

---

**本稿的核心交付目标：玩家在一局内，从清楚可辨的小刀，成长为清场能力更强、轮廓更有力量、刀光更华丽的神兵；每一次进化都带来实际收益，整个战场仍然干净、可读、可操作。**
