# 装备流派与六件出装

基线：`b8ce4f1`。上一版九件装备主要是常驻数值加成，可以全买，出装差异不足。本轮借鉴《英雄联盟》的暴击、普攻特效、生命偷取、生命成长、反伤和护盾思路，改成十四件原创装备及六件出装。保留防御、攻击、足具三类；所有物品通用于刀、剑、弓、矛。金币来源、靠近拾取、商店不暂停、十分钟节奏与糖果美术继续保留。

## 出装规则

- 最多持有六种装备，足具限一件，升级不占新位置。
- 每件最高三级，价格为基础价 + 当前等级 ×35。
- 可以出售整件装备，返还实际累计购入价的 75%，向下取整，立即释放位置。可以在六件已满时升级现有装备。
- 流派参考只是推荐与说明，没有额外套装奖励、强制绑定、自动购买或技能树。
- 商店显示五个参考方向，突出推荐装备、当前六件数量、足具限制和当前出装倾向。已购装备图标仍可滑动，点图标进入对应分类。

## 统一与边界

刀剑横扫、弓的普通箭和矛的贯穿共享暴击、吸血、当前生命伤害和冲刺强化。近战伤害可以覆盖多个目标，但每轮只为热力和电击计数一次；弓按一次普通箭轮次计数。冲刺强化只消耗在首个命中。箭仍为一次一箭、单命中，装备闪电是独立特效。

暴击与瞬步强化乘算基础命中，当前生命附加伤害独立加入、不再次暴击。过量伤害不计入吸血，吸血有每秒上限，防止刀或矛清群无限回血。

闪电、灼烧、反伤属于装备伤害，不再触发暴击、吸血、热力、电击和冲刺强化，避免递归触发。装备伤害击杀仍正常获得经验与地面金币，一只怪只掉一次。装备伤害不强制击退敌人。

护盾在本次伤害扣血前触发并吸收，可挡住将生命压过阈值的一击；冷却期不重复触发。卖掉护盾装备会移除已有护盾，冷却不会因卖买被重置。卖掉生命装备会降低上限并限制当前生命，不免费治疗。

灼烧光圈、反伤脉冲、闪电连线、护盾泡泡、吸血和瞬步强化都有对应视觉。HUD 显示热力、护盾值和强化状态。暂停冻结所有计时，减少动态和轻量模式限制装饰预算。

## 数据与旧档

本版存档 v10。v9 使用独立的原九件目录、五级上限和旧价格验证。转换时全额返还已花装备金币、清空旧装备，保留金币总收入、地面金币、等级、时间、生命比例与永久战绩；只转换一次。v1—v8 的原转换继续保留。

新存档保存六件顺序、等级、总购买额、出售返还额、热力、连击次数、护盾与冷却、吸血窗口、灼烧计时、冲刺强化和箭矢。收支满足“钱包 + 累计购买 = 金币收入 + 出售返还”；拒绝超位、双鞋、等级越界、非法退款和异常战斗计时。

- `npm test`：普通攻击与每种装备机制在四种武器上的实际行为、六件、换鞋、出售、收支、递归限制和旧档转换。
- 二十个正常输入完整对局：五种流派分别用四种武器运行，不修改生命、伤害、时钟、经验或随机流。
- `npm run test:item-builds`：实际商店、推荐、禁买第七件、升级、出售、换鞋、双指、钱包更新时购买、底栏滑动、刷新与旧档补偿。
- `npm run build`、`npm run test:offline`：类型检查、生产构建和禁网试玩。当前环境禁用文件协议，离线测试将实际 HTML 字节放入内存页面并禁网，未宣称测试过手机文件管理器。

完整对局证明可达性，不代表真人平衡结论。手机为 Chromium 触控模拟。浏览器商店截图使用明确的金币资助场景，不表示开局拥有这些金币。
