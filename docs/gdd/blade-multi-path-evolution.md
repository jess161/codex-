# 胡萝卜剑多流派进化 · 首批实现

引擎保留 Phaser 3.90 + TypeScript。沿用 `BladeRun` 的固定步长、空间网格、扇形判定、经验拾取、金币、商店、暂停与存档。没有重建游戏，也没有改动荒岛游戏。

## 一、检查结果与接入边界

基线 `7628c1b` 已有经验自动升级、成长数值、胡萝卜剑/香蕉弓入口、调味罐头树；没有六次重要成长选择。因此在原有循环上增加重要成长轨道，原经验轨道继续收经验并自动结算。新局入口固定胡萝卜剑，历史香蕉弓文件和原图保留。

本批实现六阶段要求中的全部首批范围。连续斩击、穿透剑气和三灾、万剑进入奖励池；旋转剑气、爆裂斩及其他四种觉醒只有配置与前置定义，`enabled:false`，没有伪装成已完成功能。

## 二、状态与模块

`RunState.evolution` 保存本局构筑；元素、形态和觉醒不借用旧武器索引，不会修改主武器身份。当前存档结构 v16，内容更新直接清档；没有旧档迁移。

| 模块 | 责任 |
| --- | --- |
| `evolution/types.ts` | 类型、槽位、六次时间点、普通成长节奏 |
| `evolution/config.ts` | 主形态倍率、元素参数、剑气、变异、六种觉醒与奖励定义 |
| `WeaponEvolutionSystem` | 开启选择、原子授予能力、推进阶段、结构校验 |
| `WeaponFormSystem` | 形态与自动成长/强化合成后的装备数值 |
| `AttackMutationSystem` | 斩击次数、剑气穿透和觉醒弹数 |
| `ElementSystem` | 商店与附魔的有效元素、状态施加、持续伤害、雷电充能规则 |
| `ElementReactionSystem` | 双元素配方、三灾组合、独立反应冷却与伤害 |
| `UltimateAwakeningSystem` | 前置检查与觉醒资格 |
| `UpgradeOptionPool` | 互斥、槽位、已获得能力、可用性过滤，构造三个有效选项 |

主形态最多 1、变异最多 2、有效元素最多 3、觉醒最多 1。主形态和觉醒选定后本局不能更换。同名元素只有一个槽、最多Ⅱ级。普通数值强化可重复选。

## 三、双轨节奏

经验仍由击杀与拾取提供；新局最高 Lv.21，即 20 次自动升级。第 n 次升级最早在 n×27 秒结算，经验不足就继续收集，富余经验保留；结算不暂停。伤害、尺寸、攻击速度和暴击自动提高，沿用小尺寸、0.95 秒初始间隔和逐级尺寸增长。旧熟练度等级只作原数值与展示用途，不代表主形态或终极觉醒。

重要成长采用 `upgrade` 模式，暂停模拟、攻击、状态计时、怪物和游戏时间。暂停菜单/后台恢复后仍回到待选状态，选择完成才继续。

| 时间 | 奖励池重点 |
| --- | --- |
| 1:00 | 三种互斥主形态，固定三个选项 |
| 2:30 | 连续斩击；剑气形态额外可选穿透；不足三个补数值强化 |
| 4:00 | 保证提供缺失三灾元素中的一对；另有雷元素/强化选择 |
| 5:30 | 保证提供缺失的三灾元素，受三槽限制；余位可提供变异或强化 |
| 7:00 | 已满足条件的三灾/万剑觉醒优先；不满足就提供有效构筑与强化 |
| 8:30 | 已有觉醒可升至Ⅱ阶；尚未觉醒且此时符合条件仍可选择觉醒 |

例如不买元素罐：巨剑/双刃/剑气 → 连续斩击 → 火冰双附魔 → 毒 → 三灾觉醒 → 觉醒精炼。没有随机稀有掉落要求。剑气 → 穿透 → 任意元素 → 任意强化 → 万剑觉醒 → 精炼也是有效路线。分支选择仍会付出机会成本。

## 四、主形态与判定

| 形态 | 每击伤害 | 剑身长度 | 攻击间隔 | 基础斩击数 |
| --- | ---: | ---: | ---: | ---: |
| 巨剑 | ×1.65 | ×1.48 | ×1.28 | 1 |
| 双刃 | ×0.64 | ×0.82 | ×0.74 | 2 |
| 剑气 | ×0.80 | ×1.08 | ×1.00 | 1＋每斩剑气 |

长度倍率作用于握点到剑尖，前方手持距离仍为 16。近战继续用原 45° 扇形与当前武器距离。双刃两张同源短剑分别挥砍，每斩独立判定；连续斩击额外加一次，动画时长分配到整轮之内，避免额外斩击被动画锁抵消。

剑气每斩从角色处发出，射程 360、速度 420，造成当前单击攻击力的 75%；沿移动线段作扫掠碰撞，每道剑气记录命中目标 ID。默认命中 1 个目标，穿透变异可命中 5 个。所有远程剑气沿用 32 发在场上限。

## 五、元素、罐头与反应

商店保留共同普通罐 → 电/火/毒稀有 → 对应史诗的七件树、价格、原位升级、出售与三件装备位置。附魔和罐头的元素取并集、等级取较高值；购物升级不会叠出第四个元素，界面会说明元素槽已满。出售只移除罐头贡献，不移除已选附魔；三灾觉醒会封存所需的三种附魔，出售支持罐头后觉醒仍成立。

火持续 3 秒，重复命中刷新；毒最多 5 层，持续 4/5 秒；冰寒冷 2 秒，三击冻结普通怪 0.8/1.2 秒，精英和首领只减速，冻结有 4 秒冷却。雷每整轮普攻充能一次，双刃、追加斩、多目标和剑气命中不重复计数；普通/Ⅱ级需 5/4 轮。初始连接 4 个不同目标，Lv.6/11/16/21 各增加 1 个至 8。已有罐头的伤害参数沿用，数值配置集中在 `ELEMENT_RULES`。

六种双元素配方：冷热冲击、毒火爆发、霜毒侵蚀、雷火过载、霜雷震荡、毒雷激荡。火冰毒齐备时用三灾冲击替代双元素反应；组合不替换武器形态。每种反应有 2–2.4 秒整把武器共享冷却，不因命中多个敌人、换目标或双刃高攻速而重置。反应独立计算范围伤害；带减速的反应对首领/精英减弱。

普通斩击和剑气可以施加元素；燃烧、毒、雷、爆燃、反应均走次级伤害路径，不再施加元素或触发反应。爆燃不会继续引发爆燃。沿用仅普攻或燃烧击杀引发火焰死亡爆燃的规则。

## 六、首批觉醒

| 觉醒 | 前置 | Ⅰ阶 | Ⅱ阶 |
| --- | --- | --- | --- |
| 三灾 | 火＋冰＋毒，任意形态 | 三灾反应 140% 伤害，范围 96，冷却 1.8 秒 | 200%，120，1.4 秒 |

## 七、美术与交付边界

形态复用已获认可的参考图胡萝卜剑：巨剑增大、双刃双持、剑气保持长剑。元素材质分别在叶柄冰壳、刀身毒液、根尖火焰；雷在护手的短电弧。三元素采用分区而非全剑粒子覆盖。待机和挥砍都读取实际有效元素。

本批实际调用 `image_gen.imagegen`，以新剑原图生成结霜叶柄，原 PNG/提示词、透明裁切与 WebP、来源清单和静态缩略图均保留。双持/缩放由渲染代码实现，没有宣称这些几何变换是新生成原画。
