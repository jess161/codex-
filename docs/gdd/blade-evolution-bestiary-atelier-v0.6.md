# 怪物、刀具鉴赏与受伤声 v0.6

本补充建立在 v0.5 平行名刀设计上。十二把名刀依然开局任选、单局固定，掌握阶段和锻造上限不变。

## 新怪物

新增五种普通形态，与原有软团、疾爪、甲壳、吐弹者共同构成九种普通形态；另保留精英和首领。新怪物有独立轮廓与行为，分批加入十分钟试炼。

| 名称 | 开始出现 | 行为与应对 |
| --- | --- | --- |
| 裂壳母团 | 01:30 | 低速追近，死亡时裂出两只幼团，适合预留清场空间。 |
| 裂壳幼团 | 母团分裂时 | 低生命、高速度，不继续分裂。出生有 0.45 秒保护预警，这段时间不会攻击，也不能被命中。 |
| 赤角冲兽 | 02:45 | 0.8 秒红色直线路径预警，随后以 300 速度沿锁定方向冲锋 0.55 秒，收势 1.1 秒。普通接触伤害 10，冲锋 16。 |
| 游灯幽魂 | 04:00 | 追逐时交替侧向飘移，0.6 秒青色路径预警后以 245 速度突进 0.36 秒，收势 0.85 秒。普通接触伤害 8，突进 11。 |
| 针背刺团 | 05:30 | 保持中距离，六道橙色射线预警 0.85 秒，再发射六根尖刺。方向之间留有间隙，单根伤害 8，速度 130。 |

普通刷怪保留早期缓和、后期密集的节奏。自然生成池包含八类，幼团仅由分裂产生。吐弹者最多 6、母团最多 12、冲兽最多 8、幽魂最多 10、刺团最多 3。普通模式总敌人预算仍从 120 增至 280，轻量从 80 增至 180；分裂也遵守总预算。

尖刺和旧弹丸共享标准 32 / 轻量 24 的弹丸预算；不足六个空位时整轮尖刺不发射，保持预警与间隙含义稳定。寒意、冻结、眩晕、击退和故事被动适用于新怪物。冻结会暂停其攻击准备，不会在冻结时暗中发射。

死亡、经验和分裂共用一次结算路径，幼团有独立编号、经验与出生预警，不重复奖励母团。读档保存新种类、当前预警、冲锋方向以及尖刺的种类和伤害；旧存档不含新弹丸字段时仍按原有 12 伤害弹丸处理，继续使用 v5。

图鉴新增“怪物志”，展示十一种生物的轮廓、行为、登场时间与应对提示。

## 刀具细节与鉴赏

十二把刀共享战斗与图鉴的原创轮廓，增加研磨刃线、分层金属斜面、细刻纹、缠柄、铆饰与刀装细节。不同流派各有工艺主题：霜晶、暗浪、云雷、火脉、月弧、素白留光等。材质与纹样是本作的美术演绎，不作为原作考据或武器排名。

点击图鉴刀图上的“旋转鉴赏”，打开独立鉴赏窗口：

- 鼠标或单指拖动：以轨迹球自由旋转，包括翻到背面与滚转。
- 滚轮或双指捏合：缩放，范围 55%—210%。
- 自动转台：绕竖轴持续转动，可随时停止，手动拖动会关闭自动。
- 复位 / 双击 / R：恢复初始角度和 100% 尺寸。
- 方向键旋转，Shift + 方向键滚转；加减号缩放。
- 下拉选刀或左右按钮：不退出窗口即可鉴赏其他刀。
- Esc 或关闭：回到原来的图鉴卡片；Tab 在鉴赏控件内循环。

支持 WebGL 的设备展示真正有厚度、倒角、刀装和立体缠柄的模型。模型由本作 SVG 轮廓生成，使用本地纹理和展示灯光，无需联网下载模型。无法使用 WebGL 或上下文丢失时，保留可旋转、缩放的平面鉴赏，界面明确显示当前模式。

鉴赏只改变展示，不改变本局选择、尺寸、生命、经验、时钟、蓄势或 RNG。游戏保持暂停。关闭后释放模型、纹理、环境与 WebGL 上下文；静止时不持续提交展示帧。手机窗口可纵向滚动，关闭按钮保持可达。

## 怪物受伤声

真实伤害事件携带怪物种类、近战 / 刀气 / 被动 / 灼烧来源，以及是否致命。已有刀刃命中声保留，新增独立的怪物受伤声：

| 家族 | 音色方向 |
| --- | --- |
| 软团、母团 | 湿润、弹性的下降啾鸣 |
| 疾爪、幼团 | 短而高的惊叫 |
| 甲壳 | 带颗粒碰响的低声 |
| 吐弹者 | 气泡与呼气感 |
| 赤角冲兽 | 低沉鼻哼 |
| 游灯幽魂 | 轻而空灵的气声 |
| 针背刺团 | 干燥、细碎的颤鸣 |
| 精英、首领 | 更低、更厚的受击声 |

致命受击的音高更低、尾部更长。全局至少间隔 85 毫秒，同一家族至少 150 毫秒，避免巨刃同时命中百怪时叠成噪声。非致命灼烧跳伤不重复发声；灼烧致命仍可触发。主输出使用动态压缩控制瞬时音量。

声音在首次交互后由 Web Audio 本地合成，无远程音频或录音素材。音频变化使用自己的固定噪声，不消耗战斗随机状态。设置新增“怪物受伤声”独立开关，主声音开关仍控制全部音效；偏好保存，旧用户默认开启。

## 验证

新增规则检查覆盖分裂次数和预算、幼体出生保护、预警锁向、幽魂绕行、六向尖刺间隙、弹丸预算、冻结暂停攻击、声音事件与快照。完整对局继续验证十二把名刀的正常操作可达性。

浏览器检查覆盖全部十二个立体模型、鼠标旋转、转台与静止帧、手机单指与双指、上下文丢失、平面回退、焦点恢复、静音与读档。受伤声通过实际命中触发，并从 Web Audio 分析器测量波形峰值和均方根，确认输出有效且未削波。
