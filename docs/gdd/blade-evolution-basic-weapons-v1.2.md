# 四种基础武器重构

基线：`reconstruct/latest-from-conversation` 的 `6080d8d`。该基线是十二把刀加三把弓，不含本轮重构。

## 本轮范围

仅修改割草游戏。开局只选普通刀、剑、弓、矛；首页、选武器、图鉴、鉴赏和继续游戏均使用四种基础身份。技能树暂不做，不增加技能点、分支、解锁条件或升级菜单；原自动等级成长和地面道具保留。

旧名刀与三种元素弓的技能不转成新武器的技能。四种基础武器只有各自普攻和共用瞬步，道具效果继续生效。

## 攻击与视觉

| 身份 | 伤害倍率 | 间隔基数 | 距离 | 判定 |
| --- | --- | --- | --- | --- |
| 刀 | 1.4 | .70 秒 | 90 | 170° 扇形，一次横扫多个目标 |
| 剑 | .95 | .34 秒 | 80 | 76° 扇形，短准备 / 快斩 / 短收势 |
| 弓 | 1.3 | .58 秒 | 340 | 每轮一支普通箭，速度 720，沿线段碰撞，首个目标命中后消失 |
| 矛 | 1.5 | .80 秒 | 150 | 前方胶囊线段，初始半宽 6，贯穿全部沿线目标 |

实际间隔包含现有重量、道具和动作时长约束，所以长矛初始约 .805 秒。剑的成长扫角上限 110°，保持窄幅身份。矛宽随宽度道具的平方根增长，上限半宽 22，沿刺击全长保持恒宽；身后不命中。矛在伤害结算前跟随本轮原目标瞄准，接触后锁定方向，避免近战移动导致频繁刺空。

刀剑沿实际扇形扫过，矛直线伸出再收回，在 strike 的 45% 接触帧与真实距离一致。弓有拉弦、出箭和后坐。四种普通造型使用钢刃 / 木杆 / 木弓，不复用旧名刀的外观与元素特效。战斗、选择与鉴赏共享图形路径。

基础武器不会因掌握阶段自动生成旧刀气、冰冻、灼烧、散射或元素爆炸。弓正常箭始终单发单命中；远星镜提升箭矢射程，其穿透加成继续用于道具飞刃，界面明确说明。现有道具触发的飞刃、火焰等属于道具效果，不属于新增武器技能树。

## 兼容与可选范围

不复用历史编号，以免旧存档错认武器。`TIERS[0..14]` 保留历史数据用于验证和迁移；当前 `BLADE_CATALOGUE` 只有新编号 15 刀 / 16 剑 / 17 弓 / 18 矛。新局入口拒绝选择历史编号。

读取历史存档先验证原数据，再在存储边界转换：旧弓 12—14 → 弓；匕首及剑类 1/7/8/9/11 → 剑；其他旧刀 → 刀。转换保留生命、等级、经验、旧锻造、世界、道具、掉落、时钟、随机流与战绩；清除旧武器计数、蓄力、主动、在飞攻击和武器状态。旧时长规则不变，不额外发道具。新武器存档不再转换，可精确恢复中途攻击和在飞箭矢。

## 验证入口

- `npm test`：包括横扫侧面 / 背面、剑窄幅与节奏、矛恒宽 / 旋转 / 多目标去重、单箭 / 距离 / 屏幕范围、命中视觉接触帧、全部十五种旧身份转换与新身份确定性读档。
- `npm run test:basic-weapons`：浏览器里的四种选择、共享造型、普通自动攻击、Q 无旧效果、键盘和双指、拾取、背包、暂停、精确刷新、四种鉴赏切换及旧弓继续。
- 四种武器各自正常输入完整对局：不使用基础武器不存在的绝招，不改变 HP / 伤害 / 经验 / 随机数 / 时间。收集数受武器距离和固定种子的行走路线影响，检查至少实际收集一个道具；十五种历史对局仍保留原五件门禁。
- `npm run build`：TypeScript、常规多页面构建、单文件离线构建；离线版另用无网络浏览器检查。

手机测试为 Chromium 触控模拟，并非实体手机性能测试。自动通关证明可达性，不等于真人难度结论。历史浏览器测试中的十二刀 / 三弓 / Q 绝招场景仅代表旧版本，不作为本轮 UI 验收。
