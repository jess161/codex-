# 暂停商店与开局平衡

后续 v1.6 已移除商店流派分类、推荐与自动标签，改为 [竖向装备目录](blade-evolution-vertical-shop-v1.6.md)。本文保留当时的设计记录。

基线 `6430d9c`。十四件通用装备、六个位置和五种可混搭流派继续保留。本轮按试玩反馈调整商店操作、金币掉率和武器起点。

## 商店

商店入口改为透明背景的深蓝店铺描边图标，保留“商店”文字、金币数、快捷键与清晰焦点。手机点击区至少 44 像素。

点击图标、按 B 或点击已购装备打开商店，立即暂停战斗；关闭按钮、再次点击图标、B 或 Esc 关闭后继续。商店时间不计入十分钟。

暂停冻结整个模拟：玩家与敌人移动、普攻与箭矢、敌方弹幕、金币拾取、回血、灼烧、护盾、冷却和首领时钟；视觉特效也使用暂停状态。买卖与升级可以照常操作。打开和关闭时清除键盘移动、摇杆、瞬步及累积帧，避免购物后恢复旧输入或补跑购物期间的时间。暂停期间按瞬步或点战场不会排队执行。

流派选择保留原生下拉框键盘操作。主动暂停、设置、后台切换和结算继续使用原有流程。

## 金币

普通怪从必掉金币改为 **60% 概率掉落**；每种怪的面额仍为 1—5。精英必掉 25，首领必掉 100。未掉币的击杀依然正常获得经验。金币必须走近拾取；购物期间地面金币停留原位。

掉落使用已保存的独立掉落随机流，刷新后不会重抽。已有金币、余额、购买、出售和存档不清空，也不再次发放旧装备补偿。存档结构仍为 v10。

## 初始武器

商店玩法的基础伤害基数 **20 → 13**，攻击间隔增加 10%，攻击距离缩短 10%。等级的线性伤害增长、磨合、装备数值和触发规则保留，所以削弱对开局的影响更明显。移速、生命、拾取基础范围和四种攻击形状保留。

| 武器 | 一级无装备伤害 | 实际基础间隔 | 基础距离 |
| --- | --- | --- | --- |
| 刀 | 28 → 18 | 0.70 → 0.77 秒 | 90 → 81 |
| 剑 | 19 → 12 | 0.34 → 0.37 秒 | 80 → 72 |
| 弓 | 26 → 17 | 0.58 → 0.64 秒 | 340 → 306 |
| 矛 | 30 → 20 | 0.81 → 0.89 秒 | 150 → 135 |

刀保持横扫，剑保持快斩，弓保持单支自动箭，矛保持窄直线贯穿。选武器页与图鉴使用实际商店玩法的初始属性，避免展示旧距离与间隔。历史名刀规则只用于读取旧版本。

## 验证

规则检查覆盖降低后的实际命中伤害、攻速、距离；500 次普通击杀的掉落与未掉落；精英、首领必掉；刷新后掉落序列一致。原有装备机制与历史存档检查保留。

五种流派分别用四种武器运行完整固定种子对局，只使用正常移动、瞬步、拾取与购买输入。较低金币下检验核心装备可购买和十分钟内可通关，允许以四至六件结束；六件仍是容量上限。

浏览器检查覆盖桌面、手机双指开店、整个模拟冻结、暂停购物、金币不拾取、关店恢复且无旧移动或瞬步、透明样式、键盘选择、升级出售、窄屏与旧档补偿。离线检查使用实际单文件字节并关闭网络。手机为 Chromium 触控模拟；自动对局证明可达性，不代表真人难度结论。
