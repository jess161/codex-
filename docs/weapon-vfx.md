# 胡萝卜剑：四种单元素动态光晕

沿用现有 Phaser 3 七层框架和武器原图。战斗与独立预览共用待机、攻击、命中渲染；没有修改伤害、命中判定、攻击计时、元素状态或反应计算，不消耗战斗随机数。

| 元素 | 待机 | 攻击 | 命中 |
| --- | --- | --- | --- |
| 火 FIRE | 剑刃两侧火焰跳动，少量火星向上升，呼吸 1.2 秒 | 沿真实挥砍轨迹连接橙红弧光与火舌 | 暖色火花爆裂 |
| 冰 ICE | 冰蓝寒雾慢速流动，冰晶漂浮旋转，呼吸 1.8 秒 | 冰蓝剑光和稀疏冰屑 | 旋转冰晶碎裂 |
| 毒 POISON | 紫绿雾螺旋缠绕，绿色气泡上升，脉冲 2 秒 | 紫绿腐蚀残影、气泡和液点 | 绿色毒液飞溅及少量紫雾 |
| 雷 LIGHTNING | 独立随机短电弧，每条寿命 0.05～0.15 秒，其间有间隙 | 金色锯齿电光与分叉 | 短促局部电击闪光 |

多元素仍可同时显示，本轮重点为四种单元素。命中记录触发时的元素快照，避免切换装备后把已经发生的效果换色。BattleScene.ingest() 消费已有命中事件，原来的并行元素命中渲染已移除。

## 配置和图层

所有颜色、透明度、粒子数量、周期、持续时间和质量预算集中在 `src/blade/vfx/config.ts`。`profiles.ts` 负责元素映射；`WeaponVFX.ts` 负责生命周期、姿态、呼吸、轨迹采样和短电弧；`element-renderers.ts`、`trail-renderers.ts`、`impact-renderers.ts` 分别绘制待机、攻击和命中。

WeaponSprite 保持透明度 1。InnerAura 与 OuterAura 在主体后方绘制宽雾、外焰和轮廓柔光；ElementParticles 前方只绘制稀疏边缘高光、冰晶、气泡和细电弧，避免遮挡剑身。AttackTrail、HitVFX、ReactionVFX 使用世界坐标，离开武器后在原位置淡去。

拖尾采样真实 strike 姿态，攻击切换、瞬移、角度或缩放突变会断开。暂停传入 dt=0，冻结粒子和生命周期；关闭动态效果保留静止标识；简化模式降低数量与历史样本上限。电弧使用独立有种子随机序列，在自身寿命内保持形状，寿命与间隙结束后重新生成。没有每帧随机整屏闪烁。

特效为 Phaser Graphics 程序绘制，没有重新生成、裁切或修改武器图片。图片缺失时使用明确的程序占位剑。

## 预览和构建

标题页点击“特效预览”（窄屏星形图标），或使用 `?vfx-preview=1`。支持单元素、三元素预设、形态、尺寸、旋转、挥砍、命中、融合、清空、动态和简化设置，显示状态、FPS 和活跃数量。“基础剑对照”可在普通剑原图上单独查看新增动态层，避免把原图亮边误认为动态效果。

本轮在独立预览中验证四种元素的三个状态、真实画面变化、周期、电弧寿命、效果回收、关闭动态、简化预算、手机尺寸、形态和重新进入场景。截图和实际验证记录随交付备份保存。未进行战斗试玩或运行历史游戏测试套件。

`npm run typecheck:blade` 检查割草游戏源码；`npm run build:blade` 包含该检查、生产构建及离线 HTML 打包，产物为 `dist/blade-evolution.html`。根类型配置仍包含引用旧装备的历史测试，故沿用割草游戏专用配置。

内容版本由 bladeRelease() 更新，按既有规则清除旧档，不做迁移。不修改荒岛游戏，不发布 GitHub Pages，不提交未跟踪的 .agents/。
