# 胡萝卜剑动态光晕基础框架

本轮只接入无元素胡萝卜剑的渲染，不修改伤害、命中判定、攻击计时、成长、装备和元素反应计算。已有元素武器继续使用原来的外观和表现。沿用现有胡萝卜剑原图；周围光线和粒子用 Phaser Graphics 绘制，未重新生成或修改武器图片。

## 入口

标题页顶部点击“特效预览”（窄屏为星形图标），或在网页地址后添加 `?vfx-preview=1`。离线 HTML 内也有相同按钮。

独立场景 `WeaponVFXPreviewScene` 不创建 `BladeRun`。进入时暂停战斗场景，退出后恢复之前的界面；预览里的选择只保存在场景内存中。重新进入会重置。提供基础、巨剑、双刃、剑气四种已有外观；元素选项用于通用特效配色预览，不模拟元素伤害或专用粒子。支持挥砍、测试命中、融合特效、清空、尺寸、旋转、动态效果和简化特效。显示 FPS、活跃光晕/粒子/拖尾/命中/融合数量和光晕透明度。

## 图层和接入

`src/blade/vfx/WeaponVFX.ts` 持有七层：

| 层 | 坐标与用途 |
| --- | --- |
| WeaponSprite | 已有武器主体；保留握柄轴心、原图和显示尺寸 |
| InnerAura | 武器局部坐标；沿原图轮廓呼吸，待机约 0.165～0.315 |
| OuterAura | 武器局部坐标；缓慢流动的能量短线 |
| ElementParticles | 武器局部坐标；当前为通用微粒 |
| AttackTrail | 世界坐标；采样实际渲染姿态中的剑身到剑尖，连接成短时残影 |
| HitVFX | 世界坐标；消费已有命中事件，有限时长的冲击碎光 |
| ReactionVFX | 世界坐标；提供独立 `reaction(x,y,size)` 接口，预览按钮可触发通用扩散环 |

主体、内光晕、外能量和附着微粒共用一个 Container，因此跟随位置、旋转、横纵缩放。攻击依据只读的攻击编号和挥砍阶段，短暂增强光晕，然后指数平滑恢复。拖尾只记录 strike 阶段；不同攻击、瞬移、过大的角度跳变或缩放突变会断开，避免跨屏拉线。已留下的拖尾和命中特效不会跟随武器移动。

`setPose()` 只同步显示数据，`update(dt)` 推进显示，`hit()` 和 `reaction()` 只播放反馈。没有敌人引用，也不调用伤害函数、修改战斗状态或消耗战斗随机数。暂停和顿帧传入 `dt=0`；简化模式限制微粒、拖尾样本、命中和反应实例数量；关闭动态效果后保留静态柔光和较短的反馈。场景关闭清理图层、DOM 和事件监听。

图片缺失时使用明确的程序绘制占位剑；此占位图不属于图片生成素材。

## 构建

```sh
npm run typecheck:blade
npm run build:blade
```

后者包含类型检查、仅割草游戏的 Vite 生产构建和单文件离线打包，产物为 `dist/blade-evolution.html`。默认双游戏构建命令保持原样；本轮使用上述命令，不构建荒岛游戏，不执行测试或浏览器试玩。根 `tsconfig.json` 还包含历史测试，其中旧装备名已过期；`tsconfig.blade.json` 检查当前割草游戏所有源码与导入依赖，避免将历史测试误作为生产构建入口。

源码内容版本由现有 `bladeRelease()` 自动更新，按现有规则清除旧版本存档，不做迁移。
