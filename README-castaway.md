# 余生 · 无名之岛 / CASTAWAY

本游戏已保留在 `/castaway.html` 独立入口；仓库默认首页现在是《刃之进化》。

一款鲁滨孙式的中文第一人称 3D 荒岛求生游戏。暖沙、青海、林间泉水，以及一个从零开始的人。

## 开始游戏

需要 Node.js 20.19+ 或 22.12+（本环境使用 Node.js 24）。

```bash
cd /workspace/codex-
npm ci
npm run dev -- --port 5173
```

启动后在支持浏览器访问的本地开发环境中打开 Vite 提供的地址。游戏不需要 API Key、账号、后端或外部图片服务；字体使用系统字体，地形、海水、植物、资源、营地和手持工具在本地程序化生成。需要支持 WebGL 2 的浏览器。

也可运行 `npm run build`，然后用浏览器直接打开 `dist/castaway.html`。这是包含全部代码与样式的单文件离线版，不需要 Node.js 或开发服务器即可游玩。正常部署则使用整个 `dist/` 目录。

## 你的旅程

1. 拾取海漂木、碎石与野生亚麻，制作石斧。
2. 采集椰树与野果，补足食物、水分；深入密林前可以制作木矛。
3. 搭起营火与棕叶庇护所，再用集雨器保障饮水。木矛可在浅滩捕鱼，鲜鱼与木材可在营火旁烹饪。
4. 沿海岸向东，发现并打捞三次远航号残骸，获得三个关键零件。
5. 搭建求救信号台。补足补给，在庇护所休息，迎来第三天。
6. 第三天带着三份木材靠近信号台，按 E 点火，等待船只回应。

岛上有四项生存状态、加速流逝的昼夜、第二天的阵雨、野猪、五处发现区域、十个成就与四级生存经验。普通资源次日恢复，沉船和石碑物资有限。翻阅界面会暂停模拟，浏览器失去前台也会暂停。

这是一个具有完整开局、生存循环、失败与获救结局的单人游戏首版；并非原著剧情的逐章改编。

## 操作

| 操作 | 键位 |
| --- | --- |
| 移动 | WASD / 方向键；方向随视线变化 |
| 采集 / 互动 | 靠近并面向目标后按 E / 空格；锁定视角时也可左键互动 |
| 奔跑 | Shift，消耗体力 |
| 快捷补给 | 1 椰子、2 野果、3 淡水、4 烤鱼 |
| 随身行囊 | I / Tab |
| 制作与建造 | B |
| 手记与成就 | J |
| 岛屿地图 | M |
| 暂停 / 关闭界面 / 取消搭建 | Esc |
| 环顾 | 鼠标；点击画面锁定，也可按住画面拖动 |
| 手持木矛 | 制作木矛后按住 Q |

建筑需要先在制作界面选择，面向身边的空地，通过半透明预览确认位置，再按 E 搭建。手机使用左侧摇杆移动，右侧画面滑动环顾，互动按钮采集；左右手可同时操作。打开菜单会暂停游戏并释放鼠标；关闭后点击画面重新锁定。

点击右上角喇叭开启程序合成的海浪、风声与操作反馈。默认静音。

## 存档

自动保存到当前浏览器同一站点的 localStorage，每 12 秒及采集、制作等重要操作后保存。暂停菜单也可手动保存。首页出现“继续旅程”时可恢复。兼容此前 2D 版本的存档，并保存新的朝向与俯仰角。无跨设备云存档；隐私浏览、清理网站数据或更换访问地址可能导致无法找到原存档。重新开始前会询问确认。

## 构建与验证

```bash
npm run build
npm test
# 保持开发服务运行，再执行：
npm run test:castaway
```

浏览器测试默认使用 `/usr/bin/chromium`，可通过 `CHROMIUM_PATH` 覆盖；`GAME_URL` 可覆盖测试目标地址。测试截图与结果位于被 Git 忽略的 `test-results/first-person/`。

规则测试包含资源经济、工具门槛、建筑落点、消耗品、雨天集水、营火烹饪、跨天休息、野猪、死亡、存档校验与完整采集—制作—获救流程。新增测试覆盖随视线移动、目标前后方判断、视角限位、3D 场景碰撞，以及旧存档兼容。浏览器测试通过真实键盘、鼠标与多点触控验证第一人称相机、锁定视角、移动、采集、制作、左右手同时操作与菜单隔离；中后期使用明确标注的物资场景验证建筑、休息、存档恢复及结局，避免把等待时间当成测试。

## 项目结构

- `src/game/content.ts`：岛屿、资源、配方、成就与区域。
- `src/game/simulation.ts`：独立的生存规则与可序列化存档。
- `src/game/session.ts`：输入、界面与场景之间的连接。
- `src/render/terrain.ts`：地形高度、海水着色与地图。
- `src/render/models.ts`：立体资源、植被、营地与第一人称双手/工具。
- `src/render/IslandWorld.ts`：Three.js 渲染、鼠标锁定、触控环顾、瞄准交互与天气。
- `src/render/firstPerson.ts`：视线、移动与朝向的坐标转换。
- `src/ui/`：中文 DOM 界面、图标与响应式操作。
- `.agents/skills/`：已安装的 OpenAI Game Studio 技能。

项目依据 Game Studio、Three WebGL Game、Game UI Frontend 与 Game Playtest 技能实施。采用 Three.js + TypeScript + Vite，原有生存模拟保持独立。硬件渲染时提供柔和阴影，软件渲染时降低分辨率并关闭阴影以控制开销；WebGL 上下文丢失时自动保存并暂停，恢复后可继续。
